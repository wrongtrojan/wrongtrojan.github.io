CPU 比 DRAM 快几个数量级。`lw`/`sw` 每次都访问主存的话，单周期里访存路径会拉长时钟周期，流水线里转发也来不及。Cache 用更快的 SRAM 保存最近访问过的块；传输单位是块（行），常见 32 或 64 字节。

## 局部性与层次

- 时间局部性：刚访问过的地址很快再被访问，循环里的计数器、累加器都是。
- 空间局部性：邻近地址也容易被访问，顺序扫数组就是。Cache 按块填充，一次把相邻字节一并取来。

层次从寄存器到 L1/L2/L3，再到主存、磁盘。越往下容量越大、延迟越高。一次访存从最内层找起，未命中再向外走。L1 通常拆成 I-Cache 和 D-Cache，对应上一篇的结构冒险：`IF` 取指和 `MEM` 访存可以同时发生。

SRAM 每位晶体管更多，快但贵；DRAM 一位一个电容，密度高但需要刷新，慢。Cache 用前者，主存用后者。

## 组、路与块

容量由三个量决定：

- $B$：块大小（字节）
- $E$：每组几路（几行）
- $S$：组数

总容量

$$
C = S \times E \times B
$$

一行里除了 $B$ 字节数据，还要存：

- 有效位：该行是否含有效块
- 标记：用来匹配当前访问的块
- 写回时还要脏位：该行是否被修改，替换时是否写回

地址切成三段，从低到高：

- $b=\log_2 B$ 位块内偏移
- $s=\log_2 S$ 位组索引
- 剩下 $t$ 位标记

$E=1$ 是直接映射，$S=1$ 是全相联，其余是 $E$ 路组相联。

## 查找

一次读：

1. 用组索引选出唯一一组
2. 把这一组里 $E$ 个标记和地址里的标记并行比较，并看有效位
3. 命中则用偏移从该行取出要的字节
4. 缺失则向下一层取整块，填进这一组（可能替换一行），再完成这次访问

直接映射每组一行，比较一次就结束。两个经常交替使用的块若组号相同，会反复互相替换。全相联任何块可进任何行，要和所有标记比较，比较电路贵。组相联先按索引进组，再在组内查找。

## 地址切分

设 $C=64$ 字节，$B=8$ 字节，直接映射则 $E=1$，

$$
S = C/B = 8,\quad b=3,\quad s=3
$$

字节地址 $a$：

- 偏移：$a \bmod 8$，即最低 3 位
- 组号：$\lfloor a/8 \rfloor \bmod 8$，即接下来 3 位
- 标记：$\lfloor a/64 \rfloor$，即更高位

地址 0 与 64 的二进制最低 6 位都是 `000000`，组号相同、标记不同，映射到同一行，发生冲突缺失。

若改成 2 路组相联：仍是 8 行，但 $E=2$，于是 $S=4$，$s$ 少 1 位。0 和 64 仍进同一组，组内可以同时保存两行。查找要在组内比较两个标记。

## 缺失

- 冷缺失（强制缺失）：第一次访问该块。加大块只能摊薄后续访问，第一次仍然缺失；预取有时能提前填入。
- 冲突缺失：工作集小于 Cache 容量，但多个块映射到同一组。增加相联度或改变映射可以减少。
- 容量缺失：工作集大于 Cache 容量。只能增加容量或缩小工作集。

同一容量改成全相联后仍缺失，是容量缺失；全相联不缺失而组相联缺失，是冲突缺失。

组已满又要填入新块时发生替换。常用 LRU 或近似 LRU（时钟 / NRU），随机替换硬件更简单。直接映射每组只有一行，只能替换这一行。

## 写

写命中：

- 写直达：同时更新 Cache 与下一层。实现简单，下一层始终是新的；总线占用高，通常配写缓冲，不必每拍都等 DRAM。
- 写回：只改 Cache 并置脏位，该行被替换时才写回。带宽较低，替换时要写回脏行；换页或关机前也要把脏行写回。

写缺失：

- 写分配：先把块读进来再写。常和写回一起用。
- 不写分配：这次写直接交给下一层，Cache 不留这一块。常和写直达一起用。

读缺失一律分配（把块填进来）。指令 Cache 只读，没有脏位和写策略问题。

## 平均访存时间

命中时间 $t_{hit}$、缺失率 $r_{miss}$、缺失代价 $t_{miss}$：

$$
AMAT = t_{hit} + r_{miss} \cdot t_{miss}
$$

两级时，L1 缺失再看 L2：

$$
AMAT = t_{L1} + r_{L1}(t_{L2} + r_{L2} \cdot t_{mem})
$$

L1 要求低延迟，因此容量小、相联度低；L2/L3 更大，用来降低送到主存的缺失。$r_{miss}$ 即使不大，乘上几百拍的 $t_{miss}$ 仍然显著，所以访问模式要尽量用满已经填入的块。

## 数组访问与分块

按行扫描二维数组时，相邻元素多半在同一块里，一块填入后可供多次命中。按列扫描每次跳过一整行，块内其余字节还没用到就可能被替换。

```c
for (i = 0; i < n; i++)
  for (j = 0; j < n; j++)
    s += a[i][j];   /* 行优先，空间局部性好 */

for (j = 0; j < n; j++)
  for (i = 0; i < n; i++)
    s += a[i][j];   /* 列优先，步长是一行 */
```

分块（blocking）把大矩阵切成能放入 Cache 的子块，用完一块再换下一块。循环里反复使用的标量通常已在寄存器或 L1 中，影响 AMAT 的主要是大数组的步长和工作集大小。

## 与地址翻译

Cache 通常使用物理地址：先经页表 / TLB 翻译，再用 PPN 和页内偏移切分组索引与标记。也可以虚实混合索引（用虚拟地址低位作组号，物理标记作比较），使 TLB 查找与 Cache 查找重叠。缺页是翻译失败，与 Cache 缺失不是同一件事；新页刚调入时会连续出现冷缺失。
