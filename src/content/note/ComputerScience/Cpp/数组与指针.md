## 结构体、联合体与枚举体

### 结构体（struct）

结构体是一种特殊形态的类，成员、构造、成员函数等规则与 `class` 相同，唯一稳定的区别在默认访问控制属性：`struct` 中未指定访问控制属性的成员默认为公有（`public`），`class` 中未指定的则默认为私有（`private`）。因此可以用 `struct` 快速聚合若干公有数据，也可以像类一样为它写构造函数和成员函数。

### 联合体（union）

当一组数据里某些成员只在一种情况下有意义、另一些成员只在其他情况下有意义时，可以用联合体让它们共享存储。联合体的全部数据成员占用同一组内存单元，同一时刻至多只有一个成员的值有意义；联合体对象的大小至少等于最长那个成员的大小（还可能为对齐而填充）。

联合体的对象成员不能有自定义的构造函数、析构函数，也不能有重载的赋值运算符（C++11 起对“受限联合体”有所放宽，课程按这条限制掌握：带非平凡特殊成员的类型不宜直接作为传统联合体的成员）。联合体不能继承，也不支持包含多态（不能以联合体为基类去搞虚函数体系）。无名联合体只声明一个成员项的集合，不引入联合体类型名，成员由成员项的名字直接出现在外围作用域中访问。

### 枚举体（enum）

不限定作用域的枚举写作 `enum 枚举类型名 { 枚举值列表 };`，枚举常量被注入外围作用域，容易与其它名字冲突。可以指定底层整数类型：`enum 枚举类型名 : 类型 { 枚举值列表 };`，例如 `enum Color : unsigned { Red, Green };`。

限定作用域的枚举类写作 `enum class 枚举类型名 { 枚举值列表 };`，也可以写成 `enum struct 枚举类型名 { 枚举值列表 };`，二者在这里等价。枚举元素具有默认值：第一个未赋值的枚举项从 0 起，其后依次加一；也可以在声明时用赋值运算符另行给出整数值。枚举类的元素必须通过类型名访问，例如 `Color::Red`，不会污染外围作用域，也不能在没有显式转换时当成普通整数做算术。

## 数组

数组是具有一定顺序关系的对象集合体，组成数组的对象称为数组的元素。每个元素有 \(n\) 个下标的数组称为 \(n\) 维数组。下标从 0 开始。

### 数组的声明

声明形式是 `数据类型 标识符[第一维大小][第二维大小]...;`，例如 `int a[10];`、`double m[3][4];`。除了可以用初始化列表推断的第一维以外，各维大小必须是编译期常量（C++ 里不能像某些 C 扩展那样随意写变长数组）。

### 数组的使用

通过下标访问元素，例如 `a[i]`、`m[r][c]`。下标必须是整数（或可转换为整数），并且不得越界：语言不检查边界，越界是未定义行为。`a[i]` 等价于 `*(a + i)`。

### 数组的存储

数组元素在内存中顺序、连续存放，多维数组也不例外。行主序下，二维数组 `T a[R][C]` 先排完第 0 行的 `C` 个元素，再排第 1 行，以此类推。因此可以把二维数组看成“元素类型为 `T[C]` 的一维数组”。

### 数组的初始化

可以在声明时给部分或全部元素赋初值。如果列出全部元素的初值，第一维的元素个数可以不写，由编译器按列表长度推断。多维数组可以按第一维分组，用花括号把每一组括起来。数组也可以声明为常量，例如 `const int days[] = {31, 28, 31};`，此时元素不可改。

`int arr[N] = {n};` 只把第一个元素初始化为 `n`，其余元素值初始化为 0（对类类型则值初始化）。不要误以为每个元素都变成 `n`。多维数组除第一维外必须显式指定大小；第一维若省略，必须提供初始化列表：

```cpp
// 以二维数组为例
// int a[5][];   // 错误：第二维必须显式指定大小
// int a[][5];   // 错误：第一维没有提供初始化列表
int a[][3] = {{1, 3, 5}, {2}};  // 合法：第一维推断为 2，第二行未写出的元素为 0
```

### 数组作为函数参数

使用数组名传递数据时，传递的是首元素的地址，而不是整块数组的副本。形参数组与实参数组的首地址重合，后面的元素按偏移依次对应，因此函数里改 `a[i]` 就是改调用方的那块内存。写成 `void f(int a[])` 或 `void f(int a[10])` 或 `void f(int *a)` 在参数声明里通常等价，第一维的大小信息到了形参里就丢失了；需要保留第二维时写成 `void f(int a[][3])` 或 `void f(int (*a)[3])`。

### 对象数组

数组的元素也可以是自定义类类型。对象数组在创建时对每个元素调用构造函数：若没有在初始化列表里给出实参，就调用默认构造函数，因此元素类型必须能默认构造（除非你为每个元素都提供初值）。通过 `对象数组[下标].成员名` 访问该元素的公有成员；若拿的是指针，则用 `->`。

## 指针

### 内存空间的访问方式

计算机的内存储器被划分成存储单元，按一定规则编号，这个编号就是地址。地址编码的最基本单位是字节，每字节由 8 个二进制位组成。C++ 程序既可以通过变量名访问对象，也可以通过地址访问同一块内存。不传递对象的值、只传递对象的地址，可以避免复制大量数据，从而减小系统开销；这也是指针和引用作为函数参数的主要动机之一。

### 指针变量的声明

指针变量用来存放内存单元的地址。声明形式是 `数据类型 *标识符;`，这里的 `*` 是声明的一部分，表示“标识符是指针”，不是解引用运算。例如 `int *p;` 表示 `p` 指向 `int`。指针可以指向各种类型：基本类型、数组（以及数组元素）、函数、对象、以及另一个指针（多级指针）。声明多个变量时 `*` 只贴紧紧随其后的那个名字：`int *p, q;` 里只有 `p` 是指针，`q` 是 `int`。

### 与地址相关的运算 `*` 和 `&`

`*` 作为指针运算符（解引用、间接访问）是一元操作符，表示获取指针所指向的对象，例如 `*p` 是 `p` 指向的那个 `int`。`&` 作为取地址运算符也是一元的，得到一个对象的地址，例如 `&x` 的类型是 `T*`，若 `x` 的类型是 `T`。

同一个符号出现的位置不同，含义就不同：`&` 出现在声明里、类型的右侧时表示声明引用，例如 `int &r = x;`；出现在表达式里（等号右边或一般执行语句中）则表示取地址。`*` 在声明里表示指针，在表达式里表示解引用。

### 指针的赋值

可以在定义指针时初始化，也可以定义后再用赋值语句让它指向某个对象：`int *p = &x;` 或 `p = &y;`。多个指针可以同时指向同一个变量；一个指针在同一时刻只保存一个地址，也就是只指向一个对象（或为空）。

数组名称在表达式中通常会隐式转换成指向首元素的指针，但它是不能赋值的指针常量：不能写 `arr = ...` 去改 `arr` 本身。可以对数组名做指针算术而不修改 `arr`：

```cpp
int arr[10] = {0};
*(arr + 1) = 1;  // 合法：做指针运算但没有改变 arr 本身
// *++arr = 1;   // 错误：前置 ++ 会修改 arr 本身的值，数组名不是可修改的左值
```

指向常量的指针写作 `const 类型 *p;` 或 `类型 const *p;`。不能通过这个指针修改所指对象，但指针本身可以改去指向另一个对象（若那个对象的 const 性兼容）。指针类型的常量写作 `类型 * const p;`，必须初始化，指针本身的地址值不能再改，始终指向某个固定对象；若所指对象不是 const，仍可通过 `*p` 修改对象。两者叠在一起是 `const 类型 * const p;`，指向与所指对象都不可改。

一般指针的值只能赋给同类型（含 cv 限定兼容）的指针。`void *` 可以储存任何对象类型的地址（函数指针不在此列），一般只在所指对象类型暂时不确定、或与 C 接口交互时使用。从 `void *` 转回具体指针在 C++ 里必须显式转换，不能隐式赋值：

```cpp
void *void_ptr = new int(10);
// int *int_ptr = void_ptr;  // 错误：void* 不能隐式转换成 int*
int *int_ptr = static_cast<int *>(void_ptr);  // 需要显式转换
```

### 指针运算

指针是一种数据类型，可以参与部分算术运算、关系运算和赋值运算。不能对指针做乘法、除法或取模。

算术运算方面，指针可以和整数做加法或减法，表示指向位置按元素后移或前移。`p + n`（以及 `p[n]`，它等价于 `*(p + n)`）表示从 `p` 指向的位置向后移动 `n` 个元素，实际字节偏移是 `n * sizeof(所指类型)`。两个指向同一数组内（或尾后位置）的指针可以相减，得到相隔的元素个数。指针运算以所指类型的大小为单位，而不是以字节为单位——除非所指类型恰好是 `char`。一般把指针算术和数组用在一起；对并非指向数组元素的指针做任意加减，容易破坏地址数据或踩到代码段，属于未定义行为。

关系运算在指向相同类型数据的指针之间进行。两个指针相等，表示它们指向同一个地址。指针变量可以和整数 `0` 比较，`0`（以及 `NULL`、`nullptr`）专用于表示空指针。空指针不指向任何有效对象；解引用空指针是未定义行为。

### 用指针处理数组元素

标准库在 `<iterator>` 头文件里提供 `std::begin` 和 `std::end`（对内置数组有重载）。`begin` 返回指向数组首元素的指针，`end` 返回指向数组尾元素下一位置（尾后）的指针。半开区间 `[begin, end)` 可以写成循环 `for (auto p = begin(arr); p != end(arr); ++p)`，与范围 `for` 使用同一套边界约定。`end` 不能解引用。

### 指针数组

指针数组是元素都是指针变量的数组，每个元素必须是同一类型的指针。声明写作 `数据类型 *pa[下标];`，例如 `int *pa[10];` 是 10 个 `int*`。可以用若干数组（或对象）的地址初始化指针数组，每个元素存的是对应数组的首地址或对应对象的地址。

容易和“指向数组的指针”搞混。数组的指针要写成 `int (*p)[10]`，圆括号不可少；`int *p[10]` 是指针的数组。下面对比接收 `new` 的结果：

```cpp
int arr[10];
int (*p_to_arr)[10] = &arr;  // 指向含 10 个 int 的数组
int *num;
int *p[10] = {num};          // 元素是指针的数组
```

若写成 `(int*)p[10]`，那是把 `p[10]` 用 C 风格转换成 `int*`，并不是“数组指针”的声明语法。

`int **` 与二维数组也不是同一种东西：

```cpp
/* 右侧分配 10 个 int*，返回指向首个指针的指针，由二级指针接收 */
int **ptr1 = new int*[10];

/* 右侧分配 10 行、每行 20 个 int，返回指向“含 20 个 int 的一维数组”的指针
   由数组指针来接收 */
int (*ptr2)[20] = new int[10][20];
```

`new int[10][20]` 的类型是 `int (*)[20]`，不能直接赋给 `int **`。

### 指针作为函数参数

在不同函数之间按值传递大量数据时，复制开销很大。如果这些数据放在连续内存里，可以只传递起始地址。指针作为函数的形参主要有三个作用：使实参与形参指向同一块内存，达到参数的双向传递（函数里经指针写入，调用方能看见）；减少函数调用时数据传递的开销（简单对象更常用引用，需要表示“可空”或与 C 互操作时才用指针）；通过指向函数的指针传递函数代码的首地址，从而把行为本身当作参数。

### 指针型函数

指针也可以是函数的返回值。返回值类型为指针的函数称为指针型函数，用来在函数结束时把大量数据的地址从被调函数交还主调函数，而不是按值拷回整块数据。基本写法是 `数据类型 *函数名(参数表) { 函数体 }`。

绝不能返回指向局部自动变量的指针：函数返回后该对象销毁，指针悬空。需要函数制造一块在返回后仍存活的数据时，通常用 `new` 在堆上申请，由调用方负责 `delete`。

函数还可以返回指向数组的指针，常见有四种写法（`N` 为数组长度）：

1. 先给数组类型起别名：`typedef int arr[N];` 然后 `arr *fun(int i);`
2. 直接写出复杂声明：`int (*fun(int i))[N];` —— `fun` 是函数，接受 `int`，返回指向 `int[N]` 的指针。
3. 尾置返回类型：`auto fun(int i) -> int (*)[N];`
4. 用 `decltype` 对齐已有数组：`decltype(a) *fun(int);` 在 `a` 是数组时，返回类型与“指向该数组类型的指针”一致。

### 指向函数的指针

可执行程序的代码也会被调入内存并占据空间。函数名在表达式中表示该函数代码在内存中的起始地址。通常形式的函数调用，实质就是跳到这个首地址去执行。

函数指针是专门用来存放函数代码首地址的变量。声明形式是 `返回类型 (*函数指针名)(形参表);`，圆括号必须包住 `*函数指针名`，否则会被读成“返回指针的函数”。使用前需要赋值，指向一个已经存在、类型匹配的函数，例如 `fp = someFunc;` 或 `fp = &someFunc;`，然后用 `fp(args)` 或 `(*fp)(args)` 调用。

### 对象指针

每个对象在初始化之后都会在内存中占有一定空间。对象指针就是用于存放对象地址的变量。一般对象指针的声明是 `类名 *对象指针名;`。通过对象指针访问成员有两种等价写法：`对象指针名->成员名`，以及 `(*对象指针名).成员名`。箭头是“先解引用再取成员”的简写。

`this` 指针类似于 Python 里的 `self`：它隐含于类的非静态成员函数中，是指向当前对象的常量型指针（指针本身不可改去指向别的对象）。`this` 指向正被该成员函数操作的那个对象，相当于成员函数的一个隐含形参。静态成员函数没有 `this`，因此不能直接访问非静态成员。

指向类的非静态成员的指针把“成员在类布局里的偏移（以及成员函数的入口）”存进指针变量，再结合具体对象去访问。数据成员指针声明为 `类型说明符 类名::*指针名;`，例如 `int Clock::*pd;`。函数成员指针声明为 `类型说明符 (类名::*指针名)(参数表);`。对类中成员取地址必须写成 `&类名::成员名`，并且遵守访问权限：在类外只能取公有成员的地址。

通过成员指针访问时，对对象用 `.*`，对对象指针用 `->*`：

- `对象名.*数据成员指针名`，以及 `(对象名.*函数成员指针名)(参数表)`
- `对象指针名->*数据成员指针名`，以及 `(对象指针名->*函数成员指针名)(参数表)`

指向类静态成员的指针不依赖对象：静态数据成员和静态成员函数的地址可以用普通指针保存，因为它们没有 per-object 的偏移，访问也不需要 `this`。

## 动态内存分配

动态内存分配指在运行过程中按实际需要申请适量内存，使用结束后再释放。这种在程序运行过程中申请和释放的存储单元也称为堆对象。申请和释放一般称为建立和删除，运算符是 `new` 和 `delete`。

### new 运算符

`new 数据类型(初始化参数列表)` 动态创建堆对象。申请成功则返回指向新分配内存首地址的指针；申请失败会抛出 `std::bad_alloc` 异常（除非使用了 `nothrow` 版本）。

建立基本类型对象时，初始化过程就是给定初值：`int *p = new int(2);` 得到值为 2 的 `int`。如果不希望设定初始值，可以省去括号：`int *p = new int;`，此时对象默认初始化，对内置类型意味着不确定值。如果保留括号但不写实参，即 `new int()`，则值初始化，内置类型被置 0。注意 `new T`、`new T()`、`new T(args)` 三者不同：无括号是默认初始化，空括号是值初始化，有实参则按参数初始化。

建立类的实例对象时，`new` 根据初始化参数列表的类型和个数调用对应的构造函数。若类存在用户定义的默认构造函数，则 `new T` 与 `new T()` 都会调用它，二者等效。若用户未定义任何构造函数，编译器合成默认构造：`new T()` 会值初始化，从而把基本类型和指针类型的成员置 0；`new T` 则只做默认初始化，内置成员仍可能是未定义值。

分配数组用 `new T[n]`，得到 `T*`，释放必须配对 `delete[]`。`new T[n]()` 会对元素做值初始化。

### delete 运算符

`delete 指针名;` 删除由 `new` 建立的单个对象，释放该指针所指向的内存。如果被删除的是类的实例，会先调用析构函数再释放存储。`new` 建立的同一块内存只能 `delete` 一次；对同一地址多次 `delete` 会导致错误（未定义行为）。用 `new` 分配的内存必须用 `delete` 释放，否则成为“内存泄漏”。`delete` 空指针是安全的，什么也不做。`delete` 之后应把指针置为 `nullptr`，避免成为悬挂指针。

## vector 创建数组

静态数组和用 `new` 动态创建的数组都难以在语言层面检测下标越界。C++ 标准库提供了封装好的动态数组 `vector`，它是一个类模板。包含头文件 `<vector>` 后，写法是 `vector<元素类型> 数组对象名(数组长度, 元素初值);`，数组长度可以是变量。`vector` 定义的数组对象里，所有元素都会被初始化；若没有给出元素初值，则对元素做值初始化（对 `int` 即 0）。

`vector` 对象是封装后的数组类的实例，用下标 `v[i]` 访问元素，但对象名本身不是首元素地址，不能把 `vector` 对象名当成 `T*` 传给只接受裸指针的接口（需要 `&v[0]` 或 `v.data()`，且容器非空）。成员函数 `size()` 返回当前元素个数。更多接口（`push_back`、迭代器、容量）在类模板与标准库容器章节介绍。

## 深层复制与浅层复制

浅层复制只实现数据项的按值复制：若成员里有指针，副本里的指针仍指向同一地址。两个对象析构时可能对同一处动态内存 `delete` 两次，或者一个对象改了堆上数据另一个也被改掉。

深层复制要求编写复制构造函数（以及复制赋值、析构，即所谓“三法则”）使得指针指向新分配的地址，并把源对象所指内容拷过去，形成真正独立的副本。资源若交给 `vector`、`string` 等已经实现深拷贝或移动的类型，类本身往往可以不必手写。

## 字符串

### 用字符数组存储和处理字符串

字符串常量是一个隐含创建的 `char` 数组（实际是 `const char[]`），在表达式中表示该数组的首地址。可以将字符串常量赋给指向常量的字符指针：`const char *p = "hello";`。用非 const 的 `char*` 指向字面量在历史上曾被允许，修改字面量却是未定义行为，现代编译器会拒绝或警告。其他类型的指针不能指向字符串字面量。

字符串变量也可以用类似方式表示：把字符放进 `char` 数组，并在末尾放置 `'\0'`。`char` 数组需使用 `<cstring>` 里的函数处理：`strcpy` 复制，`strcmp` 按字典序比较，`strcat` 拼接，以及 `strlen`、`strchr`、`strstr` 等。

给字符数组赋初值时，末位 `'\0'` 必须占一个位置：

```cpp
// char s[3] = "abc";  // 错误：末位 '\0' 占位，需要 4 个连续地址
char s[4] = "abc";     // 合法
```

`strlen` 返回的长度不含 `'\0'`；`string` 的 `length()` / `size()` 也不计那个 C 串结束符。转义字符如 `'\n'` 在长度计算里只占 1 个字符。

`cout` 对 `char*`（以及 `const char*`）默认输出它所指向的字符串内容，而不是地址。若要输出指针的地址值，需要显式转换成 `void*`：`cout << static_cast<void *>(p);`。

常见 C 串函数如下。

| 函数 | 功能 |
|:---|:---|
| `strlen` | 字符串长度（不含 `'\0'`） |
| `strcpy` | 字符串拷贝 |
| `strcat` | 字符串拼接 |
| `strcmp` | 字符串比较 |
| `strchr` | 查找字符首次出现的位置 |
| `strstr` | 查找子串首次出现的位置 |

### string 类

C++ 预定义了字符串类 `std::string`，提供处理字符串所需的操作。使用时包含头文件 `<string>`。它封装了串的数据，以及一系列访问和修改的成员函数，自动管理内存，不必手动维护 `'\0'`。

构造函数包括：

- `string()` 建立长度为 0 的空串。
- `string(const string &rhs)` 复制构造，用另一个 `string` 初始化。
- `string(const char *s)` 用指针 `s` 指向的 C 字符串初始化 `string` 对象。
- `string(const string &rhs, unsigned int pos, unsigned int n)` 将对象 `rhs` 中的字符串从下标 `pos` 起取 `n` 个字符来初始化。
- `string(const char *s, unsigned int n)` 用指针 `s` 指向的字符序列的前 `n` 个字符初始化（不必遇到 `'\0'` 才停）。
- `string(unsigned int n, char c)` 将字符 `c` 重复 `n` 次来初始化。

`string` 重载了运算符，可以方便地完成复制（`=`）、链接（`+`、`+=`）和比较（`==`、`!=`、`<` 等）。字符串比较按字典序。不能把两个字符串字面量直接用 `+` 拼成 `string`，因为字面量是数组（转为 `const char*`），指针不允许相加：

```cpp
// string s = "hello" + "world";           // 错误：字面量转为指针后不能相加
string s = string("hello") + "world";      // 合法：先构造 string，再与 C 串拼接
```

常用成员函数包括：

- `append(const char *s)` 将字符串 `s` 添加在本串尾。
- `assign(const char *s)` 将 `s` 指向的字符串赋值给本对象。
- `compare(const string &str)` 比较本串与 `str` 的大小，小于返回负数，大于返回正数，相等返回 0。
- `insert(unsigned int pos, const char *s)` 将 `s` 指向的字符串插在下标 `pos` 之前。
- `substr(unsigned int pos, unsigned int n)` 取本串从 `pos` 起的 `n` 个字符作为子串返回。
- `find(const basic_string &str)` 查找并返回 `str` 在本串中第一次出现的位置，找不到时返回 `npos`。
- `length()` 返回串的长度（字符个数）。
- `swap(string &str)` 将本串与 `str` 中的字符串交换。

## 指针与引用

引用和指针常量在使用形式上接近：都必须在初始化时绑定（指向）某个已存在的对象，之后不能改去绑定（指向）别的对象。引用在运行时的实现最终要借助地址，与指针殊途同归，但语言规则不同。引用只能在初始化时指定被引用的对象，这一点类似于指针常量 `T * const`。引用不是独立对象，不能再对“引用本身”取一个可再赋值的地址来改变绑定；对引用取地址得到的是被引用对象的地址。引用可以更方便、也通常更安全地实现数据双向传递：形参写成 `T &` 即共享对象，且不需要在调用处写 `&`，也不存在空引用这一说（正常代码里引用必须绑到对象上）。需要表达“可能没有对象”或要做指针算术、与 C 互操作时，仍用指针。

## reinterpret_cast

`reinterpret_cast<类型>(表达式)` 可以将一种类型的指针转换成另一种类型的指针，也可以在不同类型的对象表示、函数指针、指向数据成员或成员函数的指针之间做底层重解释。它几乎不做编译期的类型相容检查，有很大的危险性和不确定性：转换后解引用可能对齐错误、strict aliasing 违规，或得到毫无意义的位模式。只应出现在真正需要底层解释的窄场景，例如与硬件或 C API 交互，并且要清楚实现约定。

## const_cast

`const_cast<类型>(表达式)` 将类型中的 `const`（或 `volatile`）属性去掉或加上。若对象原本就是 const 的，去掉 const 再写入是未定义行为。只在接口被迫接受非 const 指针、而你能保证不会修改，或对象本身确实可变、只是中间某层加了 const 的固定场合，适当地使用才是安全的。

## 易错点

### 数组初始化与数组名

`int arr[N] = {n};` 仅首元素为 `n`，其余为 0。多维数组除第一维外必须写出大小；第一维省略时必须有初始化列表。数组名本质是不能修改的地址（指针常量），`*(arr + 1) = 1` 合法，`++arr` 不合法。

### 悬挂指针与野指针

悬挂指针：`delete` 释放了指针所指内存后，没有把指针置为 `nullptr`，指针仍保存旧地址，再解引用或再 `delete` 都是错误。野指针：指针定义时没有初始化，值是随机的，可能指向任意内存。定义后应立刻初始化为有效对象或 `nullptr`。

函数不可返回局部变量的指针；需要跨函数存活的存储请用 `new` 向堆区申请，或返回对象（靠移动/复制），或让调用方提供缓冲区。

### void*、char* 与声明括号

`void*` 不能隐式赋给 `T*`。`char*` 可以指向字符串字面量（现代代码应写成 `const char*`），其它类型指针不能指向字面量。`cout` 打印 `char*` 时输出的是字符串内容，打印地址需转为 `void*`。

`(int *)p[10]` 不是数组指针的声明；指向数组写 `int (*p)[10]`，指针数组写 `int *p[10]`。`int **` 接收的是指针的指针，不能直接接收 `new int[10][20]`，后者要用 `int (*)[20]`。

### 字符串长度与字面量拼接

`char s[3] = "abc"` 没有给 `'\0'` 留位置。`strlen` 与 `string::length()` 都不计结束符，但字符数组缓冲区必须把结束符算进容量。两个字符串字面量不能写 `"hello" + "world"` 来拼 `string`，应先把一侧变成 `string` 对象。
