## 基本特点

### 抽象

数据抽象抽出的是状态：时钟的时、分、秒，落到类里就是数据成员。行为抽象抽出的是能做什么：走时、对时、显示，落到类里就是成员函数。

### 封装

封装把状态和操作放进同一个类型，实现藏在访问控制后面。外面只能走公有成员函数；实现改了、接口没变，用这个类的代码就不必跟着改。

## 类与对象

### 类的定义

类用 `class 类名 { ... };` 定义（注意右花括号后的分号）。类体内写数据成员和函数成员。数据成员描述状态；函数成员描述可施加于该状态上的操作。尚未给出对象之前，类只是类型，一般不占对象那样的存储（静态数据成员除外）。

### 类成员的访问控制

`public`（公有类型）定义了类的外部接口：类外代码可以通过对象访问这些成员。`private`（私有类型）只能被本类的成员函数访问（以及友元，见[共享与保护](/note/computerscience/cpp/共享与保护/)），来自外部的任何访问都是非法的。`protected`（保护类型）性质与私有类型相似：类外普通代码不能访问，但派生类的成员可以访问，规则见[继承与多态](/note/computerscience/cpp/继承与多态/)。`class` 默认访问是私有，`struct` 默认是公有。访问标号可以多次出现，从该标号起到下一个标号（或类结束）之间的成员都采用该访问属性。

### 对象

声明一个对象和声明一个一般变量相同：`类名 对象名;`，也可以在定义时初始化。访问对象的成员使用点运算符 `.`，例如 `c.hour`、`c.showTime()`。初始化可以是直接初始化 `Clock c(8, 30, 0);`，也可以是列表初始化 `Clock c{8, 30, 0};`。多个对象彼此独立，各有一份非静态数据成员；成员函数代码则共用一份。

### 类的成员函数

成员函数的具体实现一般写在类定义之外，并指明所属的类。类外定义的语法是 `返回值类型 类名::函数成员名(参数表) { 函数体 }`，作用域解析运算符 `::` 把函数绑到那个类上。类内只保留函数原型。

调用成员函数时，必须用 `.`（或对象指针上的 `->`）指出这次调用针对哪一个对象，这个对象称为目的对象。成员函数体内可以不写对象名、直接使用数据成员和其它成员函数，编译器会把它们理解为目的对象上的成员；需要显式写出时用 `this->成员`。

成员函数可以带默认形参值，规则与普通函数相同：默认实参从右向左给出，通常写在类内的声明上，类外定义不要重复指定。

内联成员函数有两种声明方式。隐式内联是把函数体直接放在类体内，即使不写 `inline`，这些函数也通常按内联候选处理。显式内联是为了保证类定义简洁，把函数体放在类外，并在类外定义前加 `inline`（声明与定义都应能让编译器看见内联定义，多文件时定义常放在头文件里）。

## 构造函数与析构函数

### 构造函数

构造函数的名字与类名相同，没有返回类型（连 `void` 也不写）。常见写法是 `类名(int a, int b, int c) : member1(a), member2(b), member3(c) { }`，冒号后面是成员初始化列表。构造函数的作用是在对象被创建时把对象初始化到一个特定的状态。对象被创建时将自动调用构造函数，不能像普通函数那样靠“忘记调用”来跳过初始化。

没有参数的构造函数称为默认构造函数，包括 `Clock() { ... }` 以及所有参数都有默认值、从而能在无实参时调用的构造函数。

### 默认构造函数

若类没有声明任何构造函数，编译器会隐式地合成一个默认构造函数。合成版本对成员做默认初始化：类类型成员调用它们自己的默认构造；内置类型和指针在对象被默认初始化时具有不确定值，在值初始化（如 `T()`、`T obj{}`）时被置 0。

一旦类中出现了任何一个用户声明的构造函数，编译器就不再自动生成默认构造函数。此时若还需要无参构造，必须自己写出，或使用 `= default` 请编译器合成。合成的默认构造函数可能执行错误的操作：例如类里有指针成员，合成版本不会为它 `new` 一块合法内存，只留下未初始化或空值，随后解引用就会出错。有 `const` 成员或引用成员时，合成默认构造也无法给它们提供初始值，定义这样的类必须自己写构造函数并在初始化列表里绑定这些成员。

### 委托构造函数

委托构造函数使用所属类的其它构造函数来执行它自己的初始化过程，而不是直接初始化成员。语法标志是初始化列表里写本类的另一个构造：例如 `Clock() : Clock(0, 0, 0) {}`，这里的冒号表示构造函数委托，把无参构造的工作交给三参数构造去把时、分、秒都设为 0。被委托的构造先执行完，委托者的函数体再执行。一个构造函数在初始化列表里要么委托给另一个构造，要么初始化成员，不能混用（不能一边委托一边再写成员初值）。

### 复制构造函数

复制构造函数的形态是 `类名(const 类名 &对象)`（课程里也写成 `类名(类名 &对象)`；加上 `const` 才能绑定临时对象，是通常写法）。形参是本类对象的引用，作用是使用一个已经存在的对象去初始化一个同类的新对象。若未自定义，系统会在必要时自动生成隐含的复制构造函数，按成员逐个复制（对类类型成员调用它们的复制构造，对内置成员按值拷贝）。指针成员被浅拷，只复制地址。

复制构造函数会在下列情况下被调用（或在语义上需要一份副本，编译器再决定是否省略）：

- 用类的一个对象去初始化该类的另一个对象，例如 `Clock b = a;` 或 `Clock b(a);`
- 函数的形参是类的对象（按值传递），调用时用实参初始化形参
- 函数的返回值是类的对象（按值返回），用返回的局部对象初始化调用方得到的临时量

返回局部对象时不要返回引用或指针，对象在函数结束时销毁；按值返回则可以靠复制或移动把状态带走。

### 移动构造函数

移动构造函数的形态是 `类名(类名 &&对象)`，形参是右值引用。它从将亡的对象里“窃取”资源（例如把指针成员拿走并把源对象置空），避免深拷贝的分配开销。

左值是位于赋值语句左侧那种有持久身份的对象变量，右值是赋值语句右侧那种临时的值。对持久存在的对象取引用称为左值引用 `T&`；对短暂存在、可被移走的右值取引用称为右值引用 `T&&`。右值引用必须绑定右值：`T &&引用名 = 右值;`，不能直接绑到左值上。`std::move` 可以把左值对象强制成右值（实际上是 `static_cast<T&&>`），从而匹配移动构造或移动赋值；被 `move` 之后的源对象应处于可析构、可赋值的有效但未指定状态，不要再假定它还持有原来的资源。

### 析构函数

析构函数写作 `~类名()`，例如 `~Clock() { delete[] 标识符; }`。它完成对象被删除前的清理工作，在对象生存期即将结束时被自动调用：局部对象离开块、堆对象被 `delete`、完整对象的生命结束等。析构函数不接受任何参数，因此不能重载；它可以是虚函数，以便通过基类指针删除派生类对象时能调到派生类析构——这一点在多态篇再讲，单类场景下默认不必写成虚函数。

默认（合成）析构函数只销毁成员，并不会对你用 `new` 得到的指针做 `delete`。类若自己管理堆内存，就必须自定义析构函数释放资源。析构函数里对指针 `delete` 之后，习惯上把指针置为 `nullptr`，避免成员函数在半销毁状态下误用。

### default、delete 函数

`= default` 写在默认构造、复制构造、移动构造、复制/移动赋值或析构的声明上，明确要求编译器合成那个简单版本，即使类里已经有了其它构造函数。`= delete` 删除不希望存在的操作：例如禁止拷贝时写 `T(const T&) = delete;` 以及 `T &operator=(const T&) = delete;`。除析构函数外，这些特殊成员都可以 `= delete`；把析构删掉会使对象无法在正常生命期末尾销毁，一般只用于不能落地的类型。赋值运算符写成 `operate = delete` 那种笔误应避免，正确是在对应函数签名后写 `= delete`。

## 类的组合

### 组合

组合是指一个类内嵌其它类的对象作为成员。创建外层类对象时，各个内嵌对象被自动创建，都需要被初始化：通常在外层构造函数的初始化列表里写 `内嵌成员(构造实参)`。内嵌对象的构造函数先调用，本类构造函数的函数体后执行；若有多个内嵌成员，它们的构造顺序由成员在类中的**声明顺序**决定，而不是初始化列表里写下的顺序。析构顺序与构造相反：先执行本类析构函数体，再按声明的逆序析构内嵌对象。

### 前向引用声明

两个类需要彼此提及（例如各自持有对方）时，可以前向声明：`class B;` 让编译器知道名字 `B` 是一个类。前向声明只让编译器知道“这个实体存在”，并不知道它的大小、成员和函数实现。因此在还不完整的类型上，只能声明指向它的指针或引用，以及把该类型用作函数的参数或返回类型（指针/引用或按值返回的声明，定义处仍需完整类型）。相互内嵌对象本身是不行的：那会要求对方大小已知，并且会造成无限大的布局。

允许的声明示例：

```cpp
#pragma once
class ExampleB;
class ExampleC;
class ExampleA {
    ExampleB *bptr1;  // 声明指针
    ExampleB &bref;   // 声明引用（引用必须在构造时绑定）
public:
    ExampleC FunC(ExampleC &c);  // 声明函数的参数与返回类型
};
```

禁止的操作如下。

| 禁止的操作 |
|:---|
| 实例化该类型的对象（`Example E;` 编译器需知道大小） |
| 使用 `sizeof(Example)` / `alignof(Example)`（编译器需知道大小） |
| 访问该类型的成员（`E.member`，编译器需知道成员） |
| 继承该类型（`class Example1 : public Example2 {};`，编译器需知道布局） |
| 调用该类型的成员函数（编译器需知道函数声明乃至实现） |

## 用构造函数定义类型转换

单参数（或其余参数均有默认值）的构造函数规定了从实参类型到类类型的转换。可以直接使用类名调用构造函数创建一个临时对象，例如 `Clock(8)`，再对临时对象调用成员函数。若构造函数未被 `explicit` 标记，这种转换还允许隐式发生：可以把 `int` 传给期待 `Clock` 的形参，编译器先用构造函数造出临时 `Clock`。

只允许显式执行的类型转换：在构造函数前加上 `explicit` 关键字，隐式转换被禁止，必须写清 `Clock(8)` 或 `static_cast<Clock>(8)`。转换运算符（`operator T()`）也可以做成 `explicit`，避免对象在意料之外变成 `bool` 或其它类型。需要把类对象转到其它类型时，常见做法是提供成员函数返回目标类型，或提供 `explicit operator T()`，而不是依赖隐式单参构造四处开花。

## 易错点

### 成员初始化顺序

成员的初始化顺序由类中成员的声明顺序决定，与初始化列表的书写顺序无关。下面的列表先写 `y` 再写 `x`，实际仍先初始化 `x`：

```cpp
class Example {
    int x;  // 声明顺序 1
    int y;  // 声明顺序 2
public:
    Example() : y(1), x(y) {
        // 实际顺序：先初始化 x（此时 y 尚未初始化，x(y) 读到的是不确定值），再初始化 y（值 1）
        cout << x << " " << y << endl;  // 输出：不确定值 1
    }
};
```

成员初始化列表在进入构造函数体之前完成。普通成员可以在函数体里再赋值，等于覆盖列表里的初值；`const` 成员和引用成员只能初始化、不能赋值，必须在列表中完成：

```cpp
class Example {
    int a;        // 普通成员
    const int b;  // const 成员（只能初始化，不能赋值）
    int &c;       // 引用成员（只能初始化，不能再绑定到别处）
public:
    Example(int x, int &ref) : a(x), b(x + 1), c(ref) {
        a = x * 2;  // 覆盖 a 的初始值（x → x*2）
        // b = x + 2;  // 错误：const 成员已初始化，无法赋值
        // c = ref + 1;  // 注意：这不是“重新绑定”，而是通过引用给原对象赋值；
        // 若本意是“让 c 改绑”，那做不到。引用一经绑定就固定。
        // 原笔记把 `c = ref+1` 标成错误，强调的是“引用不能在函数体里完成绑定”；
        // 绑定必须写在初始化列表里。列表写过 `c(ref)` 之后，`c = ...` 改的是 ref 所指对象。
    }
};
```

类的引用成员与常量成员应在初始化列表中完成初始化；不要指望构造函数体能给它们“补赋初值”。`const` 成员在进入函数体时已经初始化完毕，再写 `val = 10;` 是赋值而不是初始化，非法。

### 复制构造函数实现深层拷贝

指针成员若只拷地址，两个对象共享一块堆内存，析构时会释放两次。下面的类模板在复制时分配新内存，并用源对象指针所指的内容初始化；源指针为空则副本也为空。注释里原先把 `ptr` 误写成 `pr`、把 `nullptr` 误写成 `nullpr`，这里按同一套教学点改正。

```cpp
template <typename T1, typename T2>
class Example {
    T1 data;
    T2 *ptr;
public:
    Example() : data(T1()), ptr(nullptr) {}
    Example(const T1 &d, const T2 &p_val) : data(d) {
        ptr = new T2(p_val);  // 分配内存并初始化
    }
    Example(const Example &E) {
        data = E.data;
        if (E.ptr != nullptr) {  // 空指针判断，避免解引用空指针
            ptr = new T2(*E.ptr);  // 分配新内存，用源对象 ptr 指向的内容初始化
        } else {
            ptr = nullptr;
        }
    }
    ~Example() {
        delete ptr;      // 释放 ptr 指向的内存
        ptr = nullptr;   // 置空，避免悬挂
    }
};
```

完整的资源管理还需要复制赋值运算符（处理自赋值、先释放再拷贝或用拷贝交换），以及按需提供移动构造与移动赋值。能改用 `vector` / `string` 管理资源时，通常不必手写这一套。
