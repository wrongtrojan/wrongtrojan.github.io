写程序四步：编辑 `.cpp`，编译成目标文件（顺手查语法），链接库和其它模块得到可执行文件，跑起来再调试。基本单位是函数；`main` 是入口，其余函数得在声明或定义之后才能调用。

## 语言组成

### 字符集

C++ 源文件使用的字符集包括英文字母（大小写 `A`–`Z`、`a`–`z`）、数字字符 `0`–`9`，以及一批特殊字符，例如下划线 `_`、花括号 `{}`、圆括号 `()`、方括号 `[]`、分号 `;`、逗号 `,`、冒号 `:`、运算符符号和引号等。词法分析器只认这些字符拼出来的记号，注释与空白本身不产生可执行代码。

### 词法记号

词法记号（lexeme）是编译器读入源文件后切分出的最小有意义单位，主要包括关键字、标识符、文字（字面量）、操作符（运算符）、分隔符和空白。

关键字是语言本身预先定义、具有固定语义和用途的特殊标识符，例如 `int`、`return`、`class`、`if`。标识符用来给函数、变量、类、对象等命名。标识符必须以字母或下划线开头，随后可以由字母、下划线和数字组成，区分大小写，并且不能与语言关键字或已占用的运算符拼写冲突。`std`、`vector`、`string`、`cout` 这类标准库名字不是关键字；`override` 与 `final` 是上下文关键字，只在特定语法位置上被当成关键字。

文字即字面常量，例如 `42`、`3.14`、`'A'`、`"hello"`、`true`。操作符是 `+`、`=`、`<<` 这类完成运算或结合的记号。分隔符包括圆括号 `()`、花括号 `{}`、逗号 `,`、冒号 `:` 和分号 `;`。空白包括空格、制表符、换行符、回车符以及注释，它们在词法层面把记号隔开，本身不参与运算。

## 数据类型

C++ 把每个对象都归入某种类型，类型决定了对象占据多少存储、能做哪些运算。标准只保证各整数类型的最小宽度，具体字节数随平台的数据模型变化；下面按常见桌面实现说明，并标出容易记错的地方。

### 整型

`short`（通常写作 `short int`）在常见实现里占 2 字节（至少 16 位）。`int` 在常见 32/64 位实现里占 4 字节（标准只要求至少与 `short` 一样宽，实际上几乎总是 32 位）。`long`（`long int`）**并不总是 8 字节**：在 LP64 模型（Linux、macOS 的 64 位 ABI）上 `long` 是 8 字节、指针也是 8 字节；在 LLP64 模型（Windows 64 位）上 `long` 仍是 4 字节，要 8 字节整数应使用 `long long`（至少 64 位）。写跨平台代码时不要把 `long` 当成“固定 8 字节”。无符号对应类型是 `unsigned short`、`unsigned int`、`unsigned long`、`unsigned long long`。

### 浮点型

`float` 通常占 4 字节，对应单精度二进制浮点。`double` 通常占 8 字节，对应双精度。此外还有 `long double`，宽度与格式由实现决定，课程里一般以 `float` 和 `double` 为主。

### 字符型

`char` 的 `sizeof` 恒为 1，即一个字节；一个字节由 8 个二进制位组成。`char` 是否带符号由实现决定。另有 `signed char`、`unsigned char` 以及宽字符等类型，基础课里先把 `char` 当作存放一个字符或一个小整数的一字节对象即可。

### 布尔型

`bool` 的取值只有 `false` 和 `true`。标准要求 `bool` 必须能被取地址，因此它**至少占 1 字节**，常见实现里就是 1 字节；不要把它理解成“只占 1 个比特就能独立成对象”。在需要参与算术或被提升时，`false` 转为 `0`，`true` 转为 `1`。

### 类型转化

隐式转化由编译器在特定上下文里自动完成。逻辑运算以及 `if`、`while`、`?:` 的条件位置会把非零数据转化为 `true`、把零转化为 `false`。算术运算会把较窄的运算数提升到较宽的公共类型（整型提升、浮点提升以及整数与浮点混合时的转换）。赋值运算会把右侧表达式的值转换成左侧对象的类型，可能截断或丢失精度。

显式转化由程序员写出。C 风格强制转换写作 `(类型说明符)表达式`，功能上的写法 `类型说明符(表达式)` 与之类似。这两种写法可以同时完成数值转换、去掉 `const`、以及毫不相关的指针重解释，编译器很少给出精确诊断，因此现代 C++ 更主张使用下面四种具名转换操作符，它们与 C 风格转换并存，而不是互相取代：

- `static_cast<类型>(表达式)` 用于相关类型之间的转换，例如数值类型互转、`void*` 转回具体对象指针、在有继承关系时把派生类指针转为基类指针。
- `const_cast<类型>(表达式)` 专门用来去掉或加上 `const`（以及 `volatile`）限定。
- `reinterpret_cast<类型>(表达式)` 按底层表示重新解释，常用于毫不相干的指针类型之间，危险性高。
- `dynamic_cast<类型>(表达式)` 用于多态类型的安全下行转换，失败时指针得到空、引用抛出异常；细节见后续继承与多态笔记。

## 类型别名和推断

### 类型别名

`typedef` 把一个已有类型绑到新名字上，写法是 `typedef 已有类型 新类型;`，例如 `typedef unsigned long size_type;`，作用是将标识符声明成某种数据类型的同义词。`using` 做别名声明，写法是 `using 新类型 = 已有类型;`，一次只能声明一个别名，例如 `using size_type = unsigned long;`。两者在给单层类型起名时等价；嵌套模板类型上 `using` 往往更清晰。

### 类型判断

`auto` 让编译器根据初始值分析对象类型，因此定义时必须提供初始值。一次可以用 `auto` 定义多个变量，但这些变量必须能推断出同一类型。`decltype` 则根据已有表达式给出类型而不要求立刻初始化：`decltype(i) j;` 表示 `j` 与 `i` 类型一致，`j` 可以稍后赋值。`decltype((i))` 若 `i` 是左值会得到引用类型，与 `decltype(i)` 不同，写的时候要注意括号。

## 常量与变量

### 字面常量

整型常量默认按十进制书写。八进制以数字 `0` 开头，例如 `017` 表示十进制 15。十六进制以 `0x` 或 `0X` 开头，例如 `0x1F`。后缀 `u` 或 `U` 表示 `unsigned` 类型，`l`/`L` 表示 `long`，`ll`/`LL` 表示 `long long`，可以组合为 `ul`、`ull` 等。

实型常量有一般小数形式如 `3.14`、`0.5f`，以及指数形式：`e` 或 `E` 后面的整数表示 10 的次方，例如 `2.5e3` 是 \(2.5\times 10^3\)。默认类型是 `double`，后缀 `f`/`F` 得到 `float`，`l`/`L` 得到 `long double`。

字符常量用单引号括起来，例如 `'A'`，其值对应 ASCII（或实现的执行字符集）编码。转义序列如 `'\n'`、`'\t'`、`'\\'`、`'\0'` 也是字符常量；`'\0'` 是空字符，值为 0，用来标记 C 风格字符串结束。

字符串常量用双引号括起来。每个字符占一个字节（宽字符串另论），编译器在末尾添加 `'\0'` 作为结束标记，因此 `"abc"` 实际占 4 个字符位置。相邻的字符串字面量会在编译期拼接，但两个 `const char*` 指针不能用 `+` 相加。

布尔常量只有 `false` 和 `true`。空指针常量在现代 C++ 里写 `nullptr`；`NULL` 是标准库宏，不是关键字。

### 变量

变量声明由类型和名称组成，例如 `int n;`。初始化有两类写法。非列表初始化使用 `=` 或 `()`：`int n = 3;`、`int n(3);`。列表初始化使用 `{}` 或 `={}`：`int n{3};`、`int n = {3};`。列表初始化不允许窄化，把 `3.14` 列表初始化进 `int` 会报错，而 `int n = 3.14;` 只会截断。

变量的存储类决定生存期、链接和存放位置：

- `register` 在课程里表示“希望编译器把对象放进 CPU 寄存器以加快访问”。C++11 起它作为存储类说明符已被弃用，C++17 起不再具有这一语义，只保留为关键字；现在应让编译器自己分配寄存器。
- `extern` 表示对象在别处定义，本翻译单元只做声明，从而可以在所有函数和程序段（跨源文件）中使用那个对象。
- `static` 把对象放在固定地址，整个运行期间有效。写在函数内部时，局部 `static` 只在第一次执行到定义处时初始化，以后各次调用共用同一份；写在文件作用域时还带内部链接。
- `thread_local` 具有线程存储生存期：每个线程一份。它可以修饰命名空间作用域变量、块作用域变量，以及被指定为 `static` 存储类型的变量（包括静态数据成员）。
- `mutable` 只作用于类的非静态数据成员，允许在 `const` 成员函数里修改该成员。

### 符号常量

用 `const` 声明符号常量必须同时初始化：`const 类型 变量名 = 常量值;`。程序中间不可改变其值，编译器会拒绝随后的赋值。`constexpr` 要求初始化器是常量表达式，编译器会验证这一点，并暗含 `const` 属性；用 `constexpr` 标记的对象必须能在编译期求值。

## 运算符与表达式

表达式由运算符作用于操作数构成。操作数是表达式中一次运算的输入值。算元（arity）指该运算符需要的操作数个数：一元如 `!`、`*`（解引用）、`++`，二元如 `+`、`=`、`<<`，三元只有条件运算符 `?:`。

### 算术运算符

算术运算符包括一元正负号 `+` `-`，二元加、减、乘、除、取模 `+` `-` `*` `/` `%`，以及前置/后置自增自减 `++` `--`。整数除法截断向零。取模 `%` 要求运算数为整数；结果的符号跟随被除数（左操作数）：`-3 % 2` 与 `-3 % -2` 都是 `-1`，`3 % 2` 与 `3 % -2` 都是 `1`。

### 赋值运算符

基础赋值是 `=`。复合赋值把算术或位运算与赋值合成一步，包括 `+=`、`-=`、`*=`、`/=`、`%=`、`&=`、`|=`、`^=`、`<<=`、`>>=`。赋值运算符从右向左结合，`a = b = c` 先把 `c` 赋给 `b`，再赋给 `a`。

### 逗号运算符

逗号运算符 `,` 从左到右依次求值，整个逗号表达式的结果是最右边那个子表达式的值（以及值类别）。它常被误当成函数实参列表里的逗号：实参列表的逗号不是逗号运算符。若要在实参位置使用逗号运算符，必须加括号。

```cpp
#include <iostream>
using namespace std;

void Func(int, int) { return; }

int main() {
    int a = 5, b = 10;
    cout << (a, b) << endl;   // 输出为 b，即 10
    Func((1, 2), (3, 4, 5));  // 调用 Func，传入 2 和 5 两个参数
    return 0;
}
```

`func((1,2),(3,4,5))` 实际传入的是 `2` 和 `5`，因为 `(1, 2)` 的值是 `2`，`(3, 4, 5)` 的值是 `5`。

### 关系运算符

关系运算符比较两个运算数并得到 `bool`。表示大小关系的 `<`、`<=`、`>`、`>=` 优先级较高；表示等于关系的 `==` 与 `!=` 优先级较低。不要把 `==` 写成 `=`，后者是赋值。

### 逻辑运算符

逻辑非 `!`、逻辑与 `&&`、逻辑或 `||` 的优先级从高到低是 `!` 高于 `&&` 高于 `||`。`&&` 与 `||` 都有短路效应：`&&` 在左操作数为假时不再求值右操作数；`||` 在左操作数为真时不再求值右操作数。因此可以把有副作用或可能失败的运算写在右侧，用左侧先挡住。

### 条件运算符

条件运算符 `?:` 实现选择：`布尔类型表达式 ? 表达式1 : 表达式2`。条件为真时结果是表达式 1，否则是表达式 2。它是右结合的三元运算符，优先级低于逻辑或、高于赋值。

### sizeof 运算符

`sizeof` 计算某种类型或某个对象占据的字节数，结果类型是 `size_t`。`sizeof(int)`、`sizeof x` 都合法。对数组名做 `sizeof` 得到整块数组的字节数；对指针做 `sizeof` 只得到指针本身的宽度（32 位上通常 4、64 位上通常 8），二者不可混用。`sizeof` 的操作数通常不求值。

### 位运算符

位运算符按二进制位操作整数：

- 按位与 `&`：对应位都为 1 才得 1。
- 按位或 `|`：对应位有一个为 1 就得 1。
- 按位异或 `^`：对应位不同得 1。
- 按位取反 `~`：逐位取反（注意整数提升后的宽度）。
- 左移 `<<`、右移 `>>`：把位模式移动指定的位数。

移位时的补位规则如下。左移 `<<` 对所有整数类型一律在右侧补 0。右移 `>>` 对无符号整数补 0（逻辑右移）；对有符号整数补符号位（算术右移，这是常见实现，也是课程采用的规则）。移位位数为负或大于等于该宽度的位数，行为未定义，不要那样写。

| 运算类型 | 操作数类型 | 补位规则 |
|:---|:---|:---|
| 左移 `<<` | 所有整数类型 | 一律补 0 |
| 右移 `>>` | 无符号整数 | 补 0 |
| 右移 `>>` | 有符号整数 | 补符号位 |

### 运算符优先级

优先级从高到低可以记成下表。同一格内结合性要另记：赋值和条件运算右结合，多数二元运算左结合。后置 `++`/`--` 高于前置；单目运算高于乘除；位移低于加减；关系低于位移；等于低于大小比较；按位与、异或、或依次降低；逻辑与高于逻辑或；条件运算低于逻辑或；赋值更低；逗号最低。

| 运算符类型 | 具体运算符 |
|:---|:---|
| 基础/成员访问 | `()` `[]` `.` `->` `::` `++`（后置） `--`（后置） |
| 单目运算 | `!` `~` `++`（前置） `--`（前置） 一元 `+` `-` `&`（取地址） `*`（解引用） `sizeof` `typeid` `new`/`delete` 以及 `static_cast` 等类型转换 |
| 算术运算 | `*` `/` `%` 高于 `+` `-` |
| 位移运算 | `<<`（左移） `>>`（右移） |
| 关系运算 | `<` `<=` `>` `>=` 高于 `==` `!=` |
| 按位运算 | `&` 高于 `^` 高于 `\|` |
| 逻辑运算 | `&&` 高于 `\|\|` |
| 条件运算 | `?:` |
| 赋值运算 | `=` 以及 `(算术/位移/按位运算)=` |
| 逗号运算 | `,` |

### 左值与右值

左值（lvalue）指名有持久内存地址、可以出现在赋值左侧的对象。右值是临时的、没有持久身份的值。更细的划分里，将亡值（xvalue）属于右值但仍可取地址（例如把资源搬走的那个对象）。`std::move` 可以把左值转成可被移动的右值引用。

函数调用表达式本身是左值还是右值，取决于返回类型：

| 函数返回类型 | `func()` 的值类别 | 能否取地址 |
|:---|:---|:---|
| 左值引用（`T&`） | 左值（lvalue） | 可以 |
| 右值引用（`T&&`） | 将亡值（xvalue，属于右值） | 可以 |
| 值类型（`T`） | 纯右值（prvalue） | 不可以 |

返回 `T&` 时可以对调用结果取地址或再赋值；返回 `T` 时结果是临时量，不能取它的地址当作稳定对象来用。

## 数据的输出与输入

数据从一个对象流动到另一个对象，就称为流。输入流把数据送进程序，输出流把数据送出程序。标准库在 `<iostream>` 里提供 `cin`、`cout`、`cerr` 等流对象。

### 插入符与提取符

`<<` 作为流的插入符，把右侧数据写入左侧的输出流，例如 `cout << x;`。`>>` 作为提取符，从左侧输入流读入数据存到右侧对象，例如 `cin >> x;`。这两个运算符对整数还可以表示移位，靠操作数类型区分：左边是流对象时走输入输出，左边是整数时走位移。它们可以链式书写：`cout << a << b;` 因为 `operator<<` 返回流的引用。

### 简单的 I/O 控制

常用操作包括 `endl`（输出换行并刷新缓冲区）、`flush`，以及 `<iomanip>` 里的 `setw`、`setprecision`、`hex`、`dec`、`oct`、`fixed` 等。文件流和完整格式化见[标准模板库](/note/computerscience/cpp/标准模板库/)。

## 算法的基本控制结构

### 顺序结构

顺序结构按书写顺序一条条执行语句，是默认控制流。声明、表达式语句和复合语句（花括号包起来的块）都按出现次序运行。

### 选择结构

`if` 语句根据条件决定是否执行随后的语句或语句块。条件后面如果有多条语句，必须用花括号包成一块，否则只有紧跟的第一条语句受 `if` 控制。`if-else` 提供两路分支。`if-else if-else` 链在语法上等价于把下一个 `if` 嵌在前一个 `else` 里，是嵌套 `else` 的语法糖；`else` 与最近的尚无 `else` 的 `if` 配对。

`switch` 语句根据整型（或可转换为整型、以及枚举、部分实现下的其他类型）表达式选择 `case` 标号。每个 `case` 后面通常要写 `break`，否则会落入后续 `case`（fall-through）。`default` 在没有任何 `case` 匹配时执行，可以省略。`case` 标号必须是整型常量表达式。

### 循环结构

`while (条件) 语句` 先判断条件，为真才进入循环体。`do 语句 while (条件);` 先执行循环体，再判断条件，因此至少执行一次循环体。

`for (初始子句; 循环条件; 迭代表达式) 语句` 把循环变量的初始化、继续条件和每轮结束时的更新写在一起。初始子句可以声明变量，其作用域到 `for` 语句结束。范围 `for` 写作 `for (声明 : 区间)`，依次把数组、容器或其他可被 `begin`/`end` 遍历的序列中的元素绑定到声明的变量上，例如 `for (int x : arr)` 或 `for (auto &e : v)`。

`break` 从它所在的那一层循环或 `switch` 立刻跳出。`continue` 结束本轮循环体，转到本层循环的步进与条件判断，开始下一次迭代。它们只影响最内层循环（或 `switch`）。

### goto 语句

`goto` 跳转到同一函数内的标号：`goto 标识符;`，标号写作 `标识符:`。它可以跳出多层嵌套，但会打乱结构化控制流，也容易跳过初始化，几乎总有 `break`、`return` 或把逻辑拆成函数的更清晰写法。课程要求能读懂，不鼓励在新代码里使用。

## 函数的定义与使用

### 函数定义

函数定义的形态是：返回值类型、函数名、圆括号中的形式参数表、花括号中的函数体，并在需要时用 `return` 给出返回值。没有返回值时返回类型写 `void`。函数体里的 `return 表达式;` 结束调用并把值交还调用方；`void` 函数可以写无操作数的 `return;`。

### 函数调用

函数的调用必须发生在该函数已经声明或已经给出定义之后。调用时写函数名和实参表，实参按位置与形参匹配（另有默认实参、初始化列表等规则，见下）。嵌套调用是指一个函数的函数体里再调用别的函数，例如 `f(g(x))` 先完成 `g` 再把结果交给 `f`。递归调用是函数直接或间接调用自身：直接递归在本函数体内写自己的名字；间接递归则是 A 调 B、B 再调 A。递归由递推（逼近终止条件）和回归（沿着调用栈返回并汇总）两段组成，必须有不再递归的基准情形，否则栈会耗尽。

函数原型声明时可以省略形参名、只保留参数类型，例如 `int max(int, int);`。默认形参可以出现在声明里，也可以出现在定义里，但同一参数不要在声明和定义两处重复指定默认值。

### 函数参数传递

值传递把实参的值复制给形参。函数内对形参的读写只作用于这份副本，不改变实参本身。对象按值传递会调用复制构造函数（或移动），开销可能很大。

引用传递给实参起一个别名，形参就是那个别名。声明引用必须初始化，并且必须绑定到已经存在的对象。引用的底层实现是指针：编译器为引用保存被绑定对象的地址，但在语言层面上引用不是对象，不能改变绑定目标。通过引用形参修改，就是在修改实参。

默认参数在声明形参时给出初始值，例如 `void f(int a, int b = 0);`。调用时若没有对应实参传入，就使用默认值。默认实参必须从参数表右侧向左连续缺省，不能只给中间一个参数默认值而让更靠右的参数仍为必填。

可变形参分两种。实参类型相同时，可以用标准库类型 `std::initializer_list<T>` 生成一个列表对象，头文件是 `<initializer_list>`。`initializer_list` 提供 `size()` 返回元素数量，`begin()` 返回指向首元素的指针（迭代器），`end()` 返回尾元素下一位置的指针（迭代器）。调用时以花括号序列传入实参，例如 `f({1, 2, 3})`。实参类型不同时，使用可变参数模板（参数包），把类型本身也参数化，细节在模板一章展开。

### 内联函数

内联函数适合结构简单、语句少、调用频繁的小函数。写法是在函数定义前加 `inline`。编译器在编译期间把函数体嵌入调用处，从而避免一次真正的函数调用所带来的栈帧开销：参数压栈、跳转到被调地址、保存返回地址、返回时出栈等。`inline` 只是建议，编译器可以忽略；反之，类内定义的成员函数即使不写 `inline` 也常常按内联处理。

### constexpr 函数

`constexpr` 函数让编译器在编译阶段完成计算和必要的内存分配，从而在常量表达式里使用该函数，也能提升反复以常量实参调用时的效率。用于常量表达式时，返回值和形式参数都必须能作为常量。课程要求：C++11 的 `constexpr` 函数必须有且仅有一条 `return` 语句。C++14 放宽了这一限制，允许函数体里出现局部变量和多条语句，只要整体仍能在常量求值规则下执行；写作业和考试时仍按课程的“单条 `return`”来掌握，同时知道后来的标准已经放宽。

### 函数重载

函数重载允许同一作用域内函数名相同，但形参个数或类型不同；返回类型不参与重载决议。编译器根据实参的类型与个数自动确定调用哪一个重载。使用默认形参时要防止二义性：下面两个声明让 `fun(1)` 既可以匹配第一个重载（`b` 取默认值 0），也可以匹配第二个，调用不合法。

```cpp
void fun(int a, int b = 0);
void fun(int a);
```

### 系统函数

系统提供的函数一类是标准 C++ 库函数，可移植性更强；另一类是当前操作系统或编译环境特有的扩展。数学函数在头文件 `<cmath>` 中，常用的有 `sqrt`（平方根）、`abs`/`fabs`（绝对值；整数版也在 `<cstdlib>` 的 `std::abs`）、`sin`、`cos`、`tan` 以及相应的反三角函数、指数对数等。调用时注意参数与返回值多为 `double`，`float` 版本带 `f` 后缀。

## 易错点

### 程序编写与关键字

编写步骤是编辑源文件、编译成目标文件并查语法、与库链接成可执行文件、再运行调试。程序的基本模块是函数。

关键字是语言预定义的特殊标识符。下列名字**不是**关键字：自行命名的变量、函数、命名空间；标准库里的类、函数、命名空间和宏，例如命名空间 `std`，容器与类型 `string`、`vector`、`map`、`set`，输入输出 `cout`、`cin`、`endl`、`cerr`，宏与类型别名 `NULL`、`size_t`、`ssize_t`，算法与工具 `sort`、`find`、`make_pair`；各编译器的扩展以及预处理指令如 `include`、`define`（它们属于预处理，不是 C++ 关键字）。字面量、常量一般也不是关键字，但 `true`、`false`、`nullptr` 除外——它们是语言给出的字面量，具有保留含义。`override` 与 `final` 是上下文关键字。

| 类别 | 示例 |
|:---|:---|
| 命名空间 | `std` |
| 容器/类型 | `string` `vector` `map` `set` |
| 输入输出 | `cout` `cin` `endl` `cerr` |
| 宏/类型别名 | `NULL` `size_t` `ssize_t` |
| 算法/工具 | `sort` `find` `make_pair` |

### 运算符、模除与短路

位移补位、逗号从左到右取最右值、模除符号跟随被除数、`&&`/`||` 短路，上文已经用表和代码展开。再强调一次模除：

```cpp
cout << -3 % 2 << endl;   // 输出 -1
cout << -3 % -2 << endl;  // 输出 -1
cout << 3 % 2 << endl;    // 输出 1
cout << 3 % -2 << endl;   // 输出 1
```

同号或异号都看被除数的符号：左操作数为负则结果为负，左操作数为正则结果为正。

### 函数原型

原型里可以只写类型不写形参名。默认实参可以写在声明或定义中，不要两处重复指定同一个参数。带默认实参的重载最容易在“少写一个实参”时撞上两个候选，编译器报二义性。
