动态规划把重叠的子问题做成有比较的递推。找零那条记忆化递归已经碰到同一实例被算多次；这里把适用条件和状态设计写清楚，例题仍用原来的 P1103，不再另加实现。

## 核心特征

最优子结构要求问题的全局最优解可以由若干子问题的局部最优解组合得到。重叠子问题是指解决原问题时会反复遇到相同的子问题，用“缓存”储存子问题的解以避免重复计算。无后效性要求子问题的解只依赖过去的状态，不依赖于未来的状态。

## 使用DP解题的思路

问题分析先验证适用性再转换问题：判断是否满足上面三条核心特征；若问题是求解最优且能拆分子问题，再对问题做转换，降低状态设计难度。

状态定义要抓住维度和关键约束。锚定最后一步，用来解决相邻关系或递推关系；状态维度等于问题的可变约束数；状态必须满足无后效性。

边界初始化确定最基础子问题的解：这些子问题无法再拆分，解可以直接写出。状态转移则是当前状态等于子问题最优解加一步决策——明确当前状态 `dp[i][j]` 依赖哪些子状态，明确子状态到当前状态的一步决策，从而得到当前状态的最优解。最后从 DP 数组中筛查覆盖目标的状态：DP 状态是子问题的解，需要从中筛出原问题的解。

## 常见DP问题类型

组合优化求最值且有约束，状态定义技巧是锚定最后一步并加上约束维度，转移核心是子状态加决策。计数问题求路径数，同样锚定最后一步，转移只依赖子状态。背包问题是选物品，带容量或价值约束，状态常用物品数加容量维度，转移是选或不选当前物品。区间 DP 的子问题是区间 $[l,r]$，锚定区间长度或端点，转移时枚举区间分割点。

## 代码实现P1103

```cpp

#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>
#include <climits>
using namespace std;

struct Book {
    int height, width;
    bool operator<(const Book& b) const {
        return height < b.height;
    }
};

int main() {
    int n, k;
    cin >> n >> k;
    int m = n - k;  // 要保留的书的数量
    vector<Book> books(n);
    for (int i = 0; i < n; i++) {
        cin >> books[i].height >> books[i].width;
    }
    // 按高度排序
    sort(books.begin(), books.end());

    // 提取排序后的宽度数组
    vector<int> width(n);
    for (int i = 0; i < n; i++) {
        width[i] = books[i].width;
    }

    // DP数组：dp[i][j] = 前i本选j本保留，且第i本保留的最小不整齐度
    vector<vector<int>> dp(n, vector<int>(m+1, INT_MAX));
    
    // 初始化：选1本时，不整齐度为0
    for (int i = 0; i < n; i++) {
        dp[i][1] = 0;
    }

    // 状态转移
    for (int j = 2; j <= m; j++) {  // 选j本
        for (int i = j-1; i < n; i++) {  // 第i本作为最后一本（至少选j本，i≥j-1）
            for (int k = j-2; k < i; k++) {  // 前j-1本的最后一本是k
                if (dp[k][j-1] != INT_MAX) {
                    dp[i][j] = min(dp[i][j], dp[k][j-1] + abs(width[i] - width[k]));
                }
            }
        }
    }

    // 找所有选m本的最小不整齐度
    int ans = INT_MAX;
    for (int i = m-1; i < n; i++) {
        ans = min(ans, dp[i][m]);
    }

    cout << ans << endl;
    return 0;
}

```
