查找先决定表是否有序、要不要额外空间；排序则在比较次数和额外存储之间做取舍。顺序扫描、折半、散列是三条查找路；冒泡到快排是一组由慢到快、由稳到可能退化的排序。

## 搜索

顺序搜索从一端扫到另一端，时间复杂度为 $O(N)$。列表有序时可采用二分搜索，每次把区间切半，时间复杂度为 $O(\log N)$。

散列把元素集合储存在槽中以便查找，这张表叫散列表。槽的占用率称为载荷因子。散列函数将散列表中的元素与其所属位置对应起来，常常是取余函数，而且一定要高效，避免成为存储和搜索的负担。完美散列函数能给定一个元素集合，将每个元素映射到不同的槽。扩展取余的方法有折叠法——把元素切成等长的部分然后相加再求散列值——以及平方取中法：先将元素取平方，然后提取中间几位数求散列值。

冲突是指散列函数将两个元素都放入同一个槽。处理冲突要用系统化方法在散列表中安置冲突的第二个元素。开放地址法里，线性探测在散列表中寻找下一个空槽或地址，但容易造成元素出现聚集现象；平方探测是线性探测的变体，不采用固定的跨步大小。链接法则允许同一个槽上存在多个元素：发生冲突时元素仍然被插入其散列值对应的槽中；随着同一个位置上的元素越来越多，搜索变得越来越困难。

```cpp
#include <vector>

struct HashTable {
    static const int m = 17;
    std::vector<int> chain[m];
    int slot(int x) const { return ((x % m) + m) % m; }
    void insert(int x) { chain[slot(x)].push_back(x); }
    bool find(int x) const {
        for (int v : chain[slot(x)]) if (v == x) return true;
        return false;
    }
};
```

## 排序

冒泡排序是 $O(N^2)$：每一轮遍历都将下一个最大值放到正确的位置上；如果在一轮遍历中没有发生元素交换，就可以确定已经有序，使其提前终止。选择排序也是 $O(N^2)$，但每次遍历列表时只做一次交换。插入排序同样 $O(N^2)$：在列表较低的一端维护有序的子列表，并逐个将每个新元素“插入”子列表。

希尔排序可以把复杂度做到 $O(N^{3/2})$。它将列表分成数个子列表，并对每一个子列表应用插入排序。切分列表是关键：并非连续切分，而是使用增量 $i$ 切分列表。

归并排序用分治策略改进排序，本身是递归算法。基准情形是列表为空或者只有一个元素，那么已经有序；不断演进则把列表一分为二，两部分递归调用分别排序，再合并。快速排序平均 $O(N\log N)$，但有可能退化。它也采用分治策略，但不使用额外的存储空间。首先选出基准值（多种方法，尽量均匀分割），基准值最终的位置是分割点，用来切分列表。接着进行分区（若要求左小右大）：左指针找到比基准大的，右指针找到比基准小的，两者交换。若右指针小于左指针，右指针即为分割点。然后对两侧递归调用该过程。

```cpp
int binary_search(const int *a, int n, int x) {
    int lo = 0, hi = n;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < x) lo = mid + 1;
        else hi = mid;
    }
    return lo < n && a[lo] == x ? lo : -1;
}

void insertion_sort(int *a, int n) {
    for (int i = 1; i < n; ++i) {
        int key = a[i], j = i;
        while (j > 0 && a[j - 1] > key) {
            a[j] = a[j - 1];
            --j;
        }
        a[j] = key;
    }
}

void quick_sort(int *a, int l, int r) {
    if (l >= r) return;
    int pivot = a[l + (r - l) / 2];
    int i = l, j = r;
    while (i <= j) {
        while (a[i] < pivot) ++i;
        while (a[j] > pivot) --j;
        if (i <= j) {
            int t = a[i]; a[i] = a[j]; a[j] = t;
            ++i; --j;
        }
    }
    if (l < j) quick_sort(a, l, j);
    if (i < r) quick_sort(a, i, r);
}
```
