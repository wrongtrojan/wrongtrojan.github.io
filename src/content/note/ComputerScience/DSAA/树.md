树把层次关系写成边和节点。先把术语钉死，再谈实现、遍历、二叉搜索树以及需要旋转才能维持高度的几种变体。

## 树相关术语

节点可以有自己的名字“键”，也可以附带信息称作“有效载荷”。根节点是唯一没有入边的节点。一个节点通过边与子节点相连；该节点是所有这些子节点的父节点。具有同一个父节点的节点互称为兄弟节点。叶节点没有子节点。

两个节点通过一条边相连，表示它们之间存在关系。除根节点外，其他每个节点仅有一条入边，出边则可能有多条。路径是由边连接的有序节点列表。一个父节点以及其所有后代的节点和边构成一棵子树。节点 $n$ 的层数是根节点到 $n$ 的唯一路径长度。树的高度是其中节点层数的最大值。

## 树的定义

从节点与边看：有一个根节点；除根节点外其他每个节点都与唯一的父节点相连；从根节点到其他每个节点都有且只有一条路径。如果每个节点最多有两个子节点，称之为二叉树。

递归定义更短：一棵树要么为空，要么由一个根节点和零棵或多棵子树构成；每棵子树的根节点通过一条边连到父树的根节点。

## 树的实现

嵌套列表是另一种表示，把子树写进父节点的列表里即可，这里不再单独展开。更常用的是节点与指针：每个节点的所有子节点放在树节点的链表中，节点的指针可以指向兄弟或儿子。二叉树里每个节点保存键、左右孩子指针就够用。

```cpp
struct TreeNode {
    int key;
    TreeNode *left = nullptr;
    TreeNode *right = nullptr;
};

void preorder(TreeNode *t) {
    if (!t) return;
    /* visit t */ preorder(t->left); preorder(t->right);
}

TreeNode *bst_insert(TreeNode *t, int key) {
    if (!t) return new TreeNode{key};
    if (key < t->key) t->left = bst_insert(t->left, key);
    else if (key > t->key) t->right = bst_insert(t->right, key);
    return t;
}

TreeNode *bst_find(TreeNode *t, int key) {
    while (t && t->key != key)
        t = key < t->key ? t->left : t->right;
    return t;
}
```

## 树的遍历

前序遍历先访问根节点，然后递归地前序遍历左子树，最后递归地前序遍历右子树。中序遍历先递归地中序遍历左子树，然后访问根节点，最后递归地中序遍历右子树。后序遍历先递归地后序遍历右子树，然后递归地后序遍历左子树，最后访问根节点。

## 二叉树的操作

`getLeftChild()` 返回当前节点的左子节点对应二叉树，`getRightChild()` 返回右子节点对应二叉树。`setRootVal(val)` 在当前节点储存 `val` 对象，`getRootVal()` 返回当前节点存储的对象。`insertLeft(val)` 新建当前节点的左子节点，`insertRight(val)` 新建右子节点。

## 二叉搜索树(binary tree)

二叉搜索树依赖于二叉搜索性：所有小于父节点键的都在左子树，所有大于父节点键的都在右子树。把它当成映射用时，`Map()` 新建一个空映射；`put(key,val)` 往映射中加入新键值对；`get(key)` 返回 key 对应的值，如果 key 不存在返回 None；`del` 从映射中删除键值对；`len()` 返回映射中储存的键值对数目；`in` 在键存在时返回 True，否则返回 False。

实现上通过 TreeNode 类提供辅助函数，简化 BinarySearchTree 类的工作；TreeNode 类显式地将每个节点的父节点记录为它的属性。若键的插入顺序是随机的，则为 $O(\log N)$ 时间复杂度；但若按顺序插入键，会使搜索树退化成链表，时间复杂度为 $O(N)$。

## 平衡二叉搜索树(AVL树)

AVL 树是带有平衡条件的二叉查找树，保证树的高度是 $O(\log N)$：每个节点的左子树和右子树的高度最多差一。插入一个节点可能破坏这一特性，需要通过旋转来修正。

单旋转用在插入发生在外侧（左-左，右-右）时。左子树更高时进行右旋转，右子树更高时进行左旋转；旋转轴是失衡节点导致失衡一侧的子节点。双旋转用在插入发生在内侧（左-右，右-左）时：绕失衡节点失衡一侧的孙子节点做失衡方向单旋转，再绕同一节点做反方向单旋转。

## 伸展树(splay tree)

伸展树保证从空树开始任意连续 $M$ 次对树的操作最多花费 $O(M\log N)$ 时间。基本想法是：当节点被访问后，就经历一系列旋转放到根上。

简单想法是通过不断做单旋转将访问的节点推向根节点，但这个策略没有明显地改变访问路径上其他节点的状况。真正用的是展开 (splaying)。若访问节点 $x$ 只有父节点无祖节点，则 $x$ 与父节点做单旋转。“之”字形 (zig-zag / zag-zig) 先做 $x$ 与父节点单旋转，再做 $x$ 与原祖节点单旋转。“一”字形 (zig-zig / zag-zag) 先做父节点与祖节点单旋转，再做 $x$ 与父节点单旋转。

## B-树

$M$ 阶 B-树的结构特性是：树的根或是树叶，或其子节点数在 2 和 $M$ 之间；除根外，所有非树叶节点的子节点数在 $M/2$ 和 $M$ 之间；所有的树叶都在相同的深度上。B-树有多种定义，有些次要细节不尽相同。B-树一般用于数据系统。
