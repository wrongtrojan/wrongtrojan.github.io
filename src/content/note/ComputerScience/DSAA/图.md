## 图的术语及定义

顶点又称节点，可以有自己的名字称为键，也可以带有附加信息“有效载荷”。两顶点由边相连表示存在关系，边既可以单向也可以双向；若图的所有边都单向则称为有向图。边可以带权重，表示从一个顶点到另一个顶点的成本。

路径是由边连接的顶点组成的序列：无权重时路径长度是边数，有权重时是权重之和。有向图中起点和终点为同一个顶点的路径称为环；没有环的图称为无环图，没有环的有向图称为有向无环图，简称 DAG。强连通要求有向图从每一个顶点到其他顶点都存在一条路径。弱连通是有向图不是强连通，但基础图（忽略方向）是连通的。完全图则是每一对顶点间都存在一条边的图。

## 图模型

`addVertex(vert)` 向图中添加一个顶点实例。`addEdge(fromVert, toVert)` 添加一条有向边连接顶点，带权重的版本是 `addEdge(fromVert, toVert, weight)`。`getVertex(vertKey)` 在图中找到名为 `vertKey` 的顶点，`getVertices()` 返回图中所有顶点。Python 里的 `in` 在顶点存在时返回 true，否则返回 false。

## 图的实现

邻接矩阵 (adjacency matrix) 是最简单的方式：使用二维矩阵，每一行每一列都表示图中一顶点，第 $v$ 行和 $w$ 列交叉的格子中的值表示从顶点 $v$ 到顶点 $w$ 的边的权重。如果图是稠密的 (dense)，$|E|=\Theta(|V|^2)$，则邻接矩阵是合适的表示方法；但在大部分应用中，图是稀疏的 (sparse)。

邻接表 (adjacency list) 对每一个顶点使用一个表存放所有邻接的顶点，最左边的结构只是头单元 (header cell)，空间需求为 $O(|E|+|V|)$。

```cpp
#include <queue>
#include <vector>

struct Graph {
    int n;
    std::vector<std::vector<std::pair<int, int>>> adj;
    explicit Graph(int n) : n(n), adj(n) {}
    void add_edge(int u, int v, int w = 1) { adj[u].push_back({v, w}); }
};

std::vector<int> topo_sort(const Graph &g) {
    std::vector<int> indeg(g.n), order;
    for (int u = 0; u < g.n; ++u)
        for (auto [v, w] : g.adj[u]) ++indeg[v];
    std::queue<int> q;
    for (int u = 0; u < g.n; ++u) if (indeg[u] == 0) q.push(u);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (auto [v, w] : g.adj[u])
            if (--indeg[v] == 0) q.push(v);
    }
    return order;
}

std::vector<int> dijkstra(const Graph &g, int s) {
    const int inf = 1e9;
    std::vector<int> dist(g.n, inf);
    using P = std::pair<int, int>;
    std::priority_queue<P, std::vector<P>, std::greater<P>> pq;
    dist[s] = 0;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d != dist[u]) continue;
        for (auto [v, w] : g.adj[u])
            if (dist[v] > d + w) {
                dist[v] = d + w;
                pq.push({dist[v], v});
            }
    }
    return dist;
}

int prim(const Graph &g, int s = 0) {
    const int inf = 1e9;
    std::vector<int> key(g.n, inf);
    std::vector<char> in(g.n, 0);
    using P = std::pair<int, int>;
    std::priority_queue<P, std::vector<P>, std::greater<P>> pq;
    key[s] = 0;
    pq.push({0, s});
    int cost = 0;
    while (!pq.empty()) {
        auto [w, u] = pq.top(); pq.pop();
        if (in[u]) continue;
        in[u] = 1;
        cost += w;
        for (auto [v, wt] : g.adj[u])
            if (!in[v] && wt < key[v]) {
                key[v] = wt;
                pq.push({wt, v});
            }
    }
    return cost;
}
```

## 宽度优先搜索(BFS)

BFS 会访问完所有与 $s$ 相距 $k$ 的顶点后再去访问与 $s$ 相距 $k+1$ 的顶点，时间为 $O(|V|+|E|)$，典型应用是词梯问题。为记录进度，顶点没被访问时为白色，第一次被访问时标记为灰色，完成访问后标记为黑色；一旦顶点变为黑色，没有白色顶点与之相连。初次访问顶点入队，顶点被访问完全后出队，队列为空时所有可达顶点都被处理。颜色、队列模板和多源扩散见[广度优先算法](/note/computerscience/dsaa/广度优先算法/)。

## 深度优先搜索(DFS)

DFS 通过尽可能地探索分支来构建搜索树，未访问的顶点是白色的，已访问的是灰色的；递归遇到死路时必须回溯，通过栈回到上一个被访问节点，时间同样是 $O(|V|+|E|)$，典型应用是骑士周游问题。通用深度优先搜索 (General DFS) 还记录前驱节点以构建深度优先搜索树（一次多棵称为深度优先森林），增加访问完成的黑色标记，并记录第一次访问与结束顶点访问的步数。回溯、剪枝与非递归栈见[深度优先算法](/note/computerscience/dsaa/深度优先算法/)。

## 拓扑排序

对 DAG 调用深度优先搜索算法，计算每一个顶点的结束时间；基于结束时间，将顶点按照递减顺序存储在有序表中，将该有序表作为拓扑排序结果返回。也可以按入度把源点入队，即上文 `topo_sort` 的 Kahn 写法。

## 强连通单元

对图 $G$ 调用深度优先搜索算法，计算每一个顶点的结束时间；对图 $G$ 做转置得到 $G^T$；对 $G^T$ 调用深度优先搜索算法，按照结束时间的递减顺序访问顶点。得到的深度优先森林中的每一棵树都是一个强连通单元。

## 最短路径问题

Dijkstra 算法适用于简单正权图 $G=\langle V,E,W\rangle$ 中两点最短路径问题。将 $V$ 划分为 $P:\{x\mid x\text{为确定点}\}$ 与 $T:\{x\mid x\text{为未确定点}\}$，每次只从 $T$ 中找到一个未确定点转换为确定点加入 $P$。第一次将初始点加入 $P$，标记为 $(0,\lambda)$。之后每次只从 $P$ 中的点出发向 $T$ 进行标记 $(l_i,v_i)$：取前一次标记与后一次标记中 $l_i$ 更小的，若不可达则 $l_i$ 计为 $\infty$。每次标数完成后选取离初始点最近的未确定点加入 $P$，循环直到所有点加入 $P$。实现上用二叉堆维护未确定点的当前距离，见上文 `dijkstra`。

## 最小生成树

Prim 同样维护已选顶点集合 $P$。每次取一条从 $P$ 连向 $T$ 的最轻边，把该端点并入 $P$，再更新 $T$ 中各点连到 $P$ 的最小边权。堆里存的是“顶点到当前树的距离”，与 Dijkstra 几乎同一套循环，只是松弛时比较的是边权本身而不是路径长。无向连通正权图得到最小生成树；实现见上文 `prim`。
