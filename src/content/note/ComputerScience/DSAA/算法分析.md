算法是为求解一个问题需要遵循的、被清楚地指定的简单指令的集合。分析它，是在选定的计算模型下，看时间和空间随输入规模怎么长。

## 数学基础

大 O 符号描述算法时间或空间复杂度的上界，对应最坏情况。大 Ω 符号描述复杂度的下界，对应最好情况。大 Θ 符号描述复杂度的精确阶，上下界同一量级。小 o 符号描述增长速度严格低于另一个函数。

若 $T_1(N)=O(f(N))$ 且 $T_2(N)=O(g(N))$，则 $T_1(N)+T_2(N)=\max\{O(f(N)),O(g(N))\}$，而 $T_1(N)\cdot T_2(N)=O(f(N)g(N))$。若 $T(N)$ 是 $k$ 次多项式，则 $T(N)=\Theta(N^k)$。$\log_k N=O(N)$，对数增长非常缓慢。

## 模型

分析时假定做任何一件简单工作都恰好花费一个时间单元，并且模型机有无限的内存。真正要分析的对象是所使用的算法和对该算法的输入。

## 运行时间计算

一般法则可以拆成四条。法则 1：`for` 循环的运行时间至多是该循环内语句的运行时间乘以迭代次数。法则 2：嵌套的 `for` 循环里，一条语句的总运行时间是该语句时间乘以所有循环的次数。法则 3：顺序语句把运行时间求和即可。法则 4：`if-else` 语句的运行时间不超过判断加上两个代码块中运行更长者的总时间。

嵌套循环把次数相乘。下面这段对每个 `i` 扫描 `i` 右侧，语句执行次数是 $N(N-1)/2$，因此 $\Theta(N^2)$。

```cpp
int inversion_count(const int *a, int n) {
    int cnt = 0;
    for (int i = 0; i < n; ++i)
        for (int j = i + 1; j < n; ++j)
            if (a[i] > a[j]) ++cnt;
    return cnt;
}
```

单层循环扫一遍是 $\Theta(N)$，二分每次切半是 $\Theta(\log N)$。后面搜索、排序、堆和图的复杂度都按这几条法则拆。
