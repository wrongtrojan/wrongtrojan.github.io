广度优先按距离一层层推开。无权或等权最短路、层序、连通分量和多源扩散都落在这条路上。图上的白灰黑标记和 $O(|V|+|E|)$ 见[图](/note/computerscience/dsaa/图/)。

## 适用问题

无权图或等权图的最短路径里，BFS 第一次到达目标节点的路径即最短路径，例如迷宫最短路径、词梯问题。层级遍历上，BFS 天然适配按层级处理节点的场景，例如二叉树的层序遍历、图的层级划分。连通性问题用来判断图的连通性、统计连通分量数量，例如岛屿数量、无向图的连通分量统计。多源 BFS 则让多个起始节点同时开始扩散，求所有节点被覆盖的最短时间或步骤，例如树木燃烧问题、多源点的最短距离。

## BFS解题思路

先把问题抽象为图模型。节点是问题的基本单元，边是节点之间的合法转移关系，还要明确搜索的起始节点和目标节点。

核心数据结构是队列和访问标记。队列存储待处理节点，保证 FIFO 逐层遍历；访问标记记录节点是否被访问，避免重复访问。

```cpp
#include <vector>
struct Node{
    int x,y;
    int step;
}
vector<vector<bool>> visited(n,vector<bool>(m,false));
```

初始化时将所有起始节点加入队列，并将起始节点标记为已访问。然后进入核心循环，逐层遍历：取出队首，若已是目标节点可直接返回；否则按四个方向扩展相邻节点，合法且未访问则入队并把步数加一，同时标为已访问。

```cpp
int dirs[4][2]={{1,0},{-1,0},{0,1},{0,-1}};
while(!queue.empty()){
    T temp =queue.front();//取出队列首项
    queue.pop();//队列首项出队
    //若temp是目标节点可直接返回结果
    //此处省略
    int nodex=temp.x;
    int nodey=temp.y;
    //遍历与temp节点的相邻节点
    for(auto dir:dirs){
        nodex=temp.x+dir[0];
        nodey=temp.y+dir[1];
        //确保相邻节点是合法节点
        if(nodex>=0&&nodex<n&&nodey>=0&&nodey<m&&!visited[nodex][nodey]){
            queue.push({nodex,nodey,temp.step+1});
            visited[nodex][nodey]=true;
        }
    }
}
```

处理结果时，若在循环中找到目标节点，返回对应的步数或路径；若循环结束仍未找到目标，则目标不可达。
