高精度计算 (High-Precision Calculation) 通过自定义存储和模拟手工运算实现计算。常规整数类型宽度有限，再大就会溢出；核心是用字符串或数组按位保存绝对值，自己模拟竖式。

字符串直接输入、便于输出，适合输入输出频繁、需直接处理字符的场景。动态数组访问效率高、便于运算，适合乘法、除法这类运算密集型场景。顺序上通常按低位在前、高位在后存储，方便从低位开始处理进位和借位。正负号用单独的标志位存储，数值部分仅存绝对值。存储时需去除前导零，避免运算错误。

下面的四则运算以非负整数为例。带符号时用标志位（如 `bool negA = (a[0] == '-')`）记录 $A$ 和 $B$ 的符号，提取绝对值部分（如 `a = a.substr(1)`）进行运算，再根据符号和运算类型确定结果符号。

## 加法

高精度加法从低位到高位逐位相加，累加进位，最终合并结果。步骤是：反转 $A$ 和 $B$ 使低位在前；初始化进位 `carry = 0`，遍历两数的每一位；当前位总和等于 $A[i]$ 的数值加 $B[i]$ 的数值再加 `carry`，结果当前位是总和模 10，新进位是总和除以 10；遍历结束后若仍有进位，将进位添加到结果；最后反转结果，得到最终答案。两串都耗尽后若还有进位，再补一位。

```cpp
#include <algorithm>
#include <string>

std::string add(std::string a, std::string b) {
    std::reverse(a.begin(), a.end());
    std::reverse(b.begin(), b.end());
    std::string res;
    int carry = 0;
    for (size_t i = 0; i < a.size() || i < b.size() || carry; ++i) {
        int sum = carry;
        if (i < a.size()) sum += a[i] - '0';
        if (i < b.size()) sum += b[i] - '0';
        res.push_back(char('0' + sum % 10));
        carry = sum / 10;
    }
    std::reverse(res.begin(), res.end());
    return res;
}
```

## 减法

高精度减法要求被减数不小于减数。核心是从低位到高位逐位相减，处理借位：若当前位 $A[i]<B[i]$，则借位。先判断 $A\ge B$（位数多则大；位数相同则逐位比较）；反转 $A$ 和 $B$，初始化借位 `borrow = 0`，遍历每一位：当前位 $A[i]$ 的数值先减去上一位的借位；若 $A[i]<B[i]$，则 $A[i]$ 加 10，同时 `borrow = 1`；结果当前位是 $A[i]-B[i]$。最后反转结果，去除前导零。

```cpp
bool greater_or_equal(const std::string &a, const std::string &b) {
    if (a.size() != b.size()) return a.size() > b.size();
    return a >= b;
}

std::string subtract(std::string a, std::string b) {
    if (!greater_or_equal(a, b)) return "0";
    std::reverse(a.begin(), a.end());
    std::reverse(b.begin(), b.end());
    std::string res;
    int borrow = 0;
    for (size_t i = 0; i < a.size(); ++i) {
        int digit_a = a[i] - '0' - borrow;
        int digit_b = i < b.size() ? b[i] - '0' : 0;
        borrow = 0;
        if (digit_a < digit_b) {
            digit_a += 10;
            borrow = 1;
        }
        res.push_back(char('0' + digit_a - digit_b));
    }
    std::reverse(res.begin(), res.end());
    size_t start = res.find_first_not_of('0');
    return start == std::string::npos ? "0" : res.substr(start);
}
```

## 乘法

高精度乘法逐位相乘后累加，利用数组存储中间结果，最后处理进位。初始化结果数组长度为 $A$ 的位数加 $B$ 的位数；从低位到高位遍历 $A$ 的每一位和 $B$ 的每一位，乘积累加至 `resArr[i+j]`；再遍历处理数组中的进位，每一位超过 10 则向高位进位；最后将数组转换为字符串，去除前导零。每一位与另一数的每一位相乘，积累加到 `i + j` 位，最后统一处理进位。

```cpp
#include <vector>

std::string multiply(std::string a, std::string b) {
    if (a == "0" || b == "0") return "0";
    std::reverse(a.begin(), a.end());
    std::reverse(b.begin(), b.end());
    std::vector<int> acc(a.size() + b.size(), 0);
    for (size_t i = 0; i < a.size(); ++i)
        for (size_t j = 0; j < b.size(); ++j)
            acc[i + j] += (a[i] - '0') * (b[j] - '0');
    for (size_t k = 0; k + 1 < acc.size(); ++k) {
        acc[k + 1] += acc[k] / 10;
        acc[k] %= 10;
    }
    while (acc.size() > 1 && acc.back() == 0) acc.pop_back();
    std::string res;
    for (int d : acc) res.push_back(char('0' + d));
    std::reverse(res.begin(), res.end());
    return res;
}
```

## 除法

高精度除法分两种场景，实现难度差异较大。高精度除以低精度较简单：从高位往下试商，余数乘 10 再加下一位，保留余数。高精度除以高精度更复杂，可用减法模拟除法或二分法求商。
