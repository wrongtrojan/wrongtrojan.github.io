线性结构先约定操作集合，再决定用数组还是指针去实现。栈和队列都是对表的访问位置加了限制之后的特例，双端队列则两边都能进能出。

## 抽象数据类型(abstract data type)

ADT 是一些操作的集合，可以有诸如并、交、测定大小、取余、查找等操作。具体存成数组还是链表，是实现细节，不改变这组操作的含义。

## 列表(List)ADT

列表是元素的集合，每一个元素有其相对位置。它支持 `add()`、`remove()`、`search`、`isEmpty()`、`length()`、`index()`，以及 `append()`、`insert(pos,item)`、`pop()`、`pop(pos)`。

用数组实现时，插入和删除的运行时间复杂度高，因为后面的元素要整体挪动；表的大小还必须事先已知，除非另行扩容。链表允许表不连续存储：每个节点含有数据域和指向后继节点的指针域（Next 指针），最后一个节点的 Next 指向 `NULL`（0）。常留出一个标志节点，称为表头 (header) 或哑结点 (dummy node)。Delete 可以通过修改指向待删除节点的指针，使之指向下一节点来实现。

双链表在节点上再附加一个域，使节点包含指向上一个节点的指针，从而允许双向扫描。这增加了空间需求，使插入和删除的开销增加一倍，但简化了删除操作——不必再找前驱。循环链表则让最后节点反过来直指第一个节点。链表的一个典型应用是基数排序 (radix sort)。

```cpp
struct Node {
    int val;
    Node *next;
};

void list_push_front(Node *&head, int x) {
    head = new Node{x, head};
}
```

## 栈(stack)ADT

栈限制插入（进栈）和删除（出栈）只在栈顶进行，又称为 FILO 表。支持的操作是 `push()`、`pop()`、`peak()`（返回栈顶）、`isEmpty()`、`size()`。用链表实现时，操作指针的例程开销昂贵。用数组实现则只需一块连续数组和栈顶下标：`push` 把元素放进 `top+1`，`pop` 取出 `a[top]`。容量事先给定，满了要么拒绝要么扩容。

栈的应用都来自它的反转特性：匹配括号、进制转化，以及前、中、后序表达式转化。

```cpp
struct ArrayStack {
    int data[64];
    int top = -1;
    void push(int x) { data[++top] = x; }
    int pop() { return data[top--]; }
    bool empty() const { return top < 0; }
};
```

## 队列(queue)ADT

队列在队尾 (rear) 插入（入队），在队头 (front) 删除（出队），又称 FIFO 表。支持 `enqueue()`、`dequeue()`、`isEmpty()`、`size()`。数组实现通过循环数组 (circular array) 完成：头尾下标对容量取模，避免每次出队都把后面的元素往前挪。队列常用来做模拟，例如约瑟夫问题和打印任务。

```cpp
struct CircularQueue {
    int data[64];
    int head = 0, tail = 0, n = 0;
    static const int cap = 64;
    void enqueue(int x) {
        data[tail] = x;
        tail = (tail + 1) % cap;
        ++n;
    }
    int dequeue() {
        int x = data[head];
        head = (head + 1) % cap;
        --n;
        return x;
    }
};
```

## 双端队列(deque)ADT

双端队列同时具备栈和队列的特性，两端都可以插入和删除。一个直接应用是回文检测器：从两端同时取字符比较。
