优先队列按关键字而不是按进入顺序取出元素。最简实现用链表或有序表就能工作，真正常用的是二叉堆；左式堆、斜堆和二项队列再把合并变成一等公民。后面图上的 Dijkstra 和 Prim 都靠这里的 `DeleteMin`。

## 模型

优先队列至少允许 `Insert()` 插入元素，以及 `DeleteMin()` 找出、返回并删除最小元素。扩展操作还包括：`FindMin()` 返回最小元素但元素留在堆中；`isEmpty()` 判断堆是否为空；`size()` 返回堆中元素个数；`buildHeap()` 根据关键字创建堆。若能知道关键字的具体位置，还可以 `DecreaseKey()` 降低关键字的值，或 `IncreaseKey()` 增加关键字的值。

## 简单实现

用简单链表可以 $O(1)$ 执行插入，但 $O(N)$ 执行删除最小元。用有序表则相反：$O(N)$ 插入，$O(1)$ 删除最小元。用二叉查找树时两者平均运行时间均为 $O(\log N)$，通过平衡树可以避免退化成链表，但相对堆而言有许多冗余操作。

## 二叉堆(binary heap)

堆是一棵完全二叉树：非底层全填满，底层元素从左到右填入。为节点从 1 依次编号，完全二叉树可以由一个数组来表示。对节点 $i$，其左子节点为 $2i$，右子节点为 $2i+1$，父节点为 $i/2$。若使用数组，最大的堆大小需要事先估计。

堆序性是使操作被快速执行的性质，也即最小元应该在根上。任意子树也应该是堆，任意节点应该小于所有后裔。

`Insert()` 采取新元素上浮：新元素加入堆末尾，与父节点比较并交换，直到大于父节点。`DeleteMin()` 采取末元素下沉：删除根节点后，堆末元素填入空穴；与子节点比较，若比子节点大，则与更小的子节点交换，直到比两个子节点都小才停止。

```cpp
struct BinHeap {
    int a[256];
    int n = 0;
    void insert(int x) {
        int i = ++n;
        a[i] = x;
        while (i > 1 && a[i] < a[i / 2]) {
            int t = a[i]; a[i] = a[i / 2]; a[i / 2] = t;
            i /= 2;
        }
    }
    int delete_min() {
        int ans = a[1];
        a[1] = a[n--];
        int i = 1;
        while (2 * i <= n) {
            int j = 2 * i;
            if (j < n && a[j + 1] < a[j]) ++j;
            if (a[i] <= a[j]) break;
            int t = a[i]; a[i] = a[j]; a[j] = t;
            i = j;
        }
        return ans;
    }
};
```

二叉堆给后面的 Dijkstra、Prim 提供 `DeleteMin`：每次取出当前最短或最轻的边/顶点，再松弛邻居。`DecreaseKey()` 采取上浮，`IncreaseKey()` 采取下沉，其余操作同树的实现类似。

## d-堆

d-堆是二叉堆的简单推广，所有的节点都有 $d$ 个儿子。若 $d$ 不为 2 的幂，则使用数组储存后运行时间大幅增加。在插入次数比删除次数多得多时，以及二叉堆太大时，d-堆较为实用。

## 左式堆(leftist heap)

左式堆具有一定二叉堆特性，同时高效支持合并操作。零路径长 (null path length, NPL) 是节点到没有两个子节点的节点的最短路径长：具有 0 或 1 个子节点的节点 NPL 为 0，NPL(NULL) 为 $-1$。结构性要求堆中每一个节点的左子节点零路径长不小于右子节点零路径长；在右路径上有 $r$ 个节点的左式堆至少有 $2^r-1$ 个节点。堆序性与二叉堆相同。

操作的一般思路是将所有工作放在右路径进行。基本操作是合并 Merge：插入可以看作单节点堆与大堆合并，递归形成。基准情形是两堆有一个为空，则返回非空的。不断演进时假设 $\mathrm{root}(H_1)<\mathrm{root}(H_2)$：把 $H_1$ 的右子堆与 $H_2$ 合并，新的 $H_2$ 作为 $H_1$ 的新右子堆；若 $H_1$ 左右子堆不满足左式结构则交换，然后更新零路径长。

## 斜堆(skew heap)

斜堆具有堆序，但不存在对树的结构限制。任意 $M$ 次连续操作，总最坏情形运行时间是 $O(M\log N)$。除右路径上所有节点中最大者外，其他节点无条件交换左右子堆。

## 二项队列(binomial queue)

二项队列是堆序树的集合，是森林。堆序树中的每一棵都是二项树，节点数为 2 的幂。高度为 $k$ 的二项树恰好有 $2^k$ 个节点，深度为 $d$ 的节点数是二项系数 $\binom{k}{d}$。合并可以类比二进制数的加法。实现上每个节点的子节点都存在一个链表中，每个节点都有指向第一个子节点的指针。
